4. 嵌入模型：BAAI/bge-m3
5. 分块Token数：256

**画面**：上传CN100342976C.pdf和补充文本PDF

**操作**：
1. 点击"上传"按钮
2. 选择 CN100342976C.pdf
3. 选择 CN100342976C_text.pdf

### 第5段：配置系统提示词 (1分钟)
**画面**：聊天助手设置页面
**口播**：
"在聊天助手中配置专利领域知识。包括专利字段编码[72]代表发明人、[73]代表专利权人，以及10个部件的编号映射、空间关系、气流顺序、尺寸计算公式等。这些知识能帮助LLM正确理解专利文档。"

**操作**：
1. 进入"聊天助手设置"
2. 粘贴预配置的系统提示词

### 第6段：6题逐一测试 (3分钟)
**画面**：聊天界面，逐一输入6个问题并展示答案
**口播**：每道题读出问题和答案

**Q1**："根据文本信息，该静电除尘器的发明人是？"
→ 答案：A. P·吉特勒 ✅

**Q2**："根据文本信息，以下哪个描述符合该静电除尘器的特征？"
→ 答案：C. 管状入口具有单个圆锥形部分，达到外壳直径的80至95%，剩余部分采用台阶形式 ✅

**Q3**："在文件第7页的图片中，部件4相对于部件5在图片中的位置关系是？"
→ 答案：A. 部件4位于部件5的左侧 ✅

**Q4**："在文件第7页的图片中，尺寸X1，X2，X3分别代表什么部件的间隔距离？"
→ 答案：A. 配气带孔盘6，6'，6"之间的间隔距离 ✅

**Q5**："根据文件第7页图示，气流方向(7)首先经过哪个部件？紧接着会经过哪个部件？"
→ 答案：C. 先经过部件6"，再经过部件6' ✅

**Q6**："根据文件第7页图示，如果已知外壳直径D，那么h1和h2的尺寸可以用来计算什么？"
→ 答案：B. 确定配气带孔盘6，6'，6"的位置 ✅

## 录制步骤

1. 打开 OBS Studio 或 Xbox Game Bar (Win+G)
2. 选择录制窗口（RAGFlow浏览器窗口）
3. 确保麦克风正常
4. 开始录制
5. 按脚本操作
6. 结束录制，保存为 MP4

## 录制注意事项

- 关闭无关程序通知
- 确保网络稳定（API调用不超时）
- 先排练一遍再正式录制
- 每个问题等待完整回答后再问下一个
- 语速适中，清晰表达
