# 启动说明

## 1. 安装依赖
```bash
pip install -r 00_部署/requirements.txt
```

## 2. 配置环境变量
- 复制 `00_部署/.env.example` 为 `00_部署/.env`
- 按需填写以下参数：
  - `DEFAULT_MODEL_PROVIDER`：设置前端默认选中的模型服务商，可选 `deepseek` 或 `qwen`
  - `DEEPSEEK_API_KEY`
  - `DEEPSEEK_MODEL`
  - `DEEPSEEK_VISION_MODEL`（如需使用 DeepSeek 多模态时填写）
  - `DASHSCOPE_API_KEY`
  - `DASHSCOPE_TEXT_MODEL`
  - `DASHSCOPE_VISION_MODEL`

如果不填写模型参数，系统将自动进入演示模式，仍可完整体验页面与流程。
前端支持直接文本交互；未上传图片时会走纯文本链路，上传作业截图后会按当前模型能力切换到图文分析。

## 3. 启动项目
```bash
python 03_研发/app.py
```

浏览器访问：`http://127.0.0.1:5056`

## 4. 目录说明
- `00_部署`：部署配置与运行说明
- `01_测试`：自动测试与手工验证清单
- `02_设计`：需求分析、架构设计、接口说明
- `03_研发`：核心源码、模板、静态资源、示例数据
- `04_优化`：二期优化与扩展建议
