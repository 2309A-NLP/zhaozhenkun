# 页面与交互说明

## 页面定位
- 首页即教学工作台，强调现代化、卡片化、轻量玻璃拟态风格。
- 左侧聚合品牌说明、指标卡、模型矩阵状态与场景切换。
- 右侧聚合业务配置表单与结果展示区。

## 视觉规范
- 主色采用蓝紫渐变，辅以浅青色高亮与绿色/琥珀色状态提示。
- 使用 24px 大圆角卡片、16px 输入控件、清晰层级阴影与浅边框。
- 结果区采用高对比深色内容面板，适合长文阅读和讲解输出。

## 交互流程
1. 选择教学场景。
2. 选择模型服务商（DeepSeek / 千问）。
3. 输入课程、主题、问题、学习目标等内容。
4. 可直接提交纯文本内容，也可选上传作业图片或教材截图。
5. 点击生成，右侧输出结构化卡片和正文结果，并显示本次使用的模型与输入模式。
6. 助教场景会自动维护近几轮对话上下文。

## 扩展说明
- 当前上传入口面向图片与视频截图，便于后续升级到更完整的视频理解链路。
- 当前保留“可扩展语音 / 数字人”提示位，便于后续接入播报层。
- 若接入真实校务端，可增加班级视图、报告导出、权限角色切换等能力。
