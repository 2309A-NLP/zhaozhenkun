## 附录：如何运行JMeter压测

### 准备工作
1. 修改JMX文件中的变量（GUI模式或直接编辑XML）：
   - `API_KEY`: 你的API密钥
   - `CHAT_ID`: 已有的聊天ID
   - `DATASET_ID`: 已有的数据集ID
   - `PDF_PATH`: 测试PDF文件的绝对路径

2. 确保RAGFlow服务已启动
3. 确保已入库至少一个文档用于问答

### 运行场景A
```bash
# 命令行模式（推荐，资源消耗小）
jmeter -n -t jmeter_scenario_a_qa_5concurrent.jmx \
  -JAPI_KEY=your-key -JCHAT_ID=your-chat-id \
  -l results_a.jtl -e -o report_a/

# 查看报告
open report_a/index.html
```

### 运行场景B
```bash
jmeter -n -t jmeter_scenario_b_mixed_3concurrent.jmx \
  -JAPI_KEY=your-key -JCHAT_ID=your-chat-id \
  -JDATASET_ID=your-dataset-id -JPDF_PATH=/path/to/test.pdf \
  -l results_b.jtl -e -o report_b/
```

### 同时监控资源
```bash
# 在另一个终端持续监控
watch -n 5 'docker stats --no-stream ragflow-server ragflow-task-executor'
```
