# RAG PDF问答系统 — 部署指南

## 系统概述

本系统是一个基于 RAG (Retrieval-Augmented Generation) 架构的工业PDF专利文档问答系统。核心组件包括：

| 组件 | 技术选型 | 用途 |
|------|---------|------|
| PDF解析 | PyMuPDF + RapidOCR | 提取扫描件/文本PDF内容 |
| 文本分块 | 滑动窗口+句号断点 | 256字符粒度，32字符重叠 |
| 向量嵌入 | BGE-M3 (1024维, FP16) | 文本向量化 |
| 向量索引 | FAISS IndexFlatIP | 余弦相似度搜索 |
| 精排模型 | BGE-Reranker (CrossEncoder) | 候选结果重排序 |
| 大语言模型 | MiMo-v2.5-pro | 答案生成 |
| OCR引擎 | RapidOCR (ONNX) | 扫描件中文识别 |

## 环境要求

### 硬件
- **GPU**: NVIDIA RTX 5060 8GB 及以上
- **显存**: 至少 6GB（BGE-M3 + Reranker 共存约需 5GB）
- **内存**: 16GB+
- **磁盘**: 10GB（模型文件约 4GB）

### 软件
- **操作系统**: Windows 10/11 或 WSL2 (Ubuntu)
- **Python**: 3.10+
- **CUDA**: 12.x (需与 PyTorch 版本匹配)
- **Git**: 2.x

## 快速部署

### 第1步：安装Python依赖

```bash
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121

pip install pymupdf==1.24.0 \
    sentence-transformers==2.7.0 \
    faiss-gpu==1.7.2 \
    rapidocr-onnxruntime==1.3.22 \
    pillow==10.3.0 \
    numpy==1.26.4 \
    requests==2.31.0
```

### 第2步：下载模型文件

```bash
# BGE-M3 嵌入模型（约 2.2GB）
git clone https://huggingface.co/BAAI/bge-m3 /path/to/bge-m3

# BGE-Reranker 精排模型（约 1.1GB）
git clone https://huggingface.co/BAAI/bge-reranker-base /path/to/bge-reranker-base
```

或者使用 `huggingface-cli`：

```bash
pip install huggingface_hub
huggingface-cli download BAAI/bge-m3 --local-dir /path/to/bge-m3
huggingface-cli download BAAI/bge-reranker-base --local-dir /path/to/bge-reranker-base
```

### 第3步：配置API密钥

编辑 `研发/config.py`，设置 MiMo API 密钥：

```python
MIMO_API_KEY = "your-api-key-here"
MIMO_BASE_URL = "https://token-plan-cn.xiaomimimo.com/v1"
MIMO_MODEL = "mimo-v2.5-pro"
```

### 第4步：验证部署

```bash
cd rag工单14/研发
python run.py
```

预期输出：

## 故障排除

### 1. CUDA out of memory
- 降低 `EMBED_BATCH_SIZE` 为 1
- 降低 `EMBED_MAX_LENGTH` 为 512
- 关闭 FP16 改 FP32（特殊情况）

### 2. API超时
- 增加 `MIMO_TIMEOUT` 值
- 检查API密钥是否有效
- 检查网络连接

### 3. OCR识别为空
- 检查PDF是否为扫描件
- 调整RapidOCR的缩放参数
- 尝试使用更大分辨率渲染页面

### 4. 向量缓存损坏
```bash
rm -rf ~/.rag_workorder14_cache/
python run.py --rebuild
```
