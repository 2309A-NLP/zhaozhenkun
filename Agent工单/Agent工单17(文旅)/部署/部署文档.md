# 部署文档

## 目录规范
- 设计：需求分析、知识库设计、接口文档
- 研发：后端代码、静态页面、配置、数据
- 测试：接口测试、自检脚本、测试结果
- 优化：优化建议与扩展说明
- 部署：部署文档与环境变量示例

## 环境变量
复制 部署/.env.example 中的配置到你的运行环境：
- DEEPSEEK_BASE_URL=https://api.deepseek.com
- DEEPSEEK_API_KEY=你的密钥
- DEEPSEEK_MODEL=deepseek-chat
- FLASK_PORT=5057

## 安装依赖
进入目录：研发
执行：pip install -r requirements.txt

## 启动项目
运行文件：研发/run.py

## 访问地址
http://127.0.0.1:5057

## 说明
1. 前端页面独立文件：研发/static/index.html
2. 数据文件：研发/data/spots.json
3. Flask 使用延迟初始化
4. DeepSeek 未连通时自动回退模板讲解，不会报废
