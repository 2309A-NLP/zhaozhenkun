# 最终运行说明

## 运行入口
运行文件：研发/run.py

## 依赖安装
在研发目录执行：
pip install -r requirements.txt

## 如果报 pytesseract 缺失
说明你还没安装 OCR 依赖。
直接执行：
pip install pytesseract pillow faiss-cpu

## 页面访问
http://127.0.0.1:5057

## 推荐演示顺序
1. 先做文本检索：输入“故宫历史”
2. 再做千问文本检索：输入“西湖故事”
3. 再做图片多模态：上传一张图片并填写线索词
4. 展示返回结果中的 OCR结果、语音播报、多模态推荐内容

## 说明
若外部大模型接口不可用，系统会自动回退到模板答案，不影响演示。
