# 项目介绍稿

大家好，我的项目名称是《多模态文旅知识检索与生成系统》。

这个项目对应的工单是人工智能CV-AIGC-17，核心目标是面向文旅场景，支持游客通过文本、图片、语音转文本等多种方式发起查询，并结合知识库检索和大模型生成，输出导览讲解、历史文化解读、景点故事以及多模态推荐内容。

本项目的核心亮点有四个：
1. 支持多模态输入，包括文本、图片上传、图片线索输入。
2. 支持多模型增强，既接入了 DeepSeek，也接入了千问兼容多模态接口。
3. 支持知识检索与内容生成，能够输出导览、历史、故事三类讲解内容。
4. 支持 OCR、FAISS 索引、TTS 演示链路，使项目更接近真实落地版本。

这个项目的定位是课程工单最终交付版，特点是可运行、可演示、可答辩、可继续扩展。
