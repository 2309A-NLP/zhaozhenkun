# 答辩讲稿

## 一、项目背景
文旅场景中，游客往往希望通过拍照、提问、上传图片等方式快速获取景点相关知识，因此需要一个支持多模态输入和智能讲解输出的系统。

## 二、项目目标
本项目要实现多模态文旅知识检索与生成，包括：
1. 文本与图片输入
2. 景点知识检索
3. 导览讲解与文化解读生成
4. 多模态推荐输出

## 三、我的实现方案
1. 后端使用 Flask 搭建接口。
2. 知识库采用结构化+非结构化字段结合。
3. 检索层引入向量化与真实 FAISS 索引。
4. 模型层接入 DeepSeek 与千问。
5. 图片链路接入 OCR 与多模态识别。
6. 输出层增加 TTS 演示语音数据。

## 四、项目亮点
1. 支持真实图片上传。
2. 支持 OCR 文本抽取。
3. 支持 DeepSeek/千问切换。
4. 支持导览、历史、故事三类讲解。
5. 支持多模态推荐结果返回。

## 五、当前完成度
从课程工单交付角度，已经达到最终交付版标准；从工业级生产系统角度，还可继续升级真实 ASR、视频检索、权限安全体系。
