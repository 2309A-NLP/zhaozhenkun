# 老师问答稿

## 1. 这个项目解决了什么问题？
它解决了游客通过文本、图片等方式快速获取景点知识和讲解内容的问题。

## 2. 为什么说它是多模态系统？
因为它支持文本输入、图片上传、图片线索检索，并结合 OCR 与多模态模型进行理解和生成。

## 3. 你用了哪些模型或接口？
我接入了 DeepSeek 文本增强接口和千问兼容多模态接口，同时本地用了 tesseract OCR 和 faiss 索引。

## 4. 项目现在最核心的亮点是什么？
最核心的亮点是：真实图片上传 + OCR + 检索 + 大模型讲解生成 + TTS 演示输出。

## 5. 项目还有哪些可扩展方向？
后续可以接入真实 ASR、视频抽帧检索、Milvus、权限系统和内容审核体系。
