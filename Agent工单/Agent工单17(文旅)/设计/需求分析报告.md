# 需求分析报告

工单编号：人工智能CV-AIGC-17
项目名称：多模态文旅知识检索与生成系统

## 核心目标
构建一个面向游客的文旅智能体模块，支持文本、语音转文本、图片线索输入，并完成文旅知识检索、讲解词生成与多模态推荐输出。

## 功能拆解
1. 多模态输入：文本、语音转文本、图片关键词、视频线索
2. 智能检索：以文搜文、以图搜文、以图搜图
3. 内容生成：导览讲解、历史文化解读、景点故事
4. 多模态输出：文本 + 图片推荐 + 视频推荐 + 音频推荐
5. 多语言能力：中文、英文
6. 模型扩展：支持 DeepSeek 生成增强

## 当前落地
- 已实现可运行 Web 演示
- 已实现本地知识库检索
- 已实现 DeepSeek 接口接入
- 已实现前后端分离
- 已实现测试脚本与部署文档
