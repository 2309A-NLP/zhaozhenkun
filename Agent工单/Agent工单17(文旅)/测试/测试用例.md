# 测试用例

## 功能测试
1. 首页是否可以正常打开
2. /api/health 是否返回 ok
3. 文本检索“故宫历史”是否命中故宫
4. 图片线索“红墙 宫殿 古建筑”是否命中故宫
5. 英文输出是否返回英文结构
6. DeepSeek 不可用时是否自动走模板兜底
7. 千问 provider 是否可用于文本生成
8. 上传真实图片文件后是否能命中 /api/image-search

## 结构测试
1. 目录是否按五分类组织
2. 每个 Python 文件是否不超过 300 行
3. HTML 是否独立存放在 static 目录
4. 千问与 DeepSeek 配置是否存在于部署目录
