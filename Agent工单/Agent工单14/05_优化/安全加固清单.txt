# 安全加固清单

## 1. 已实施

| 措施 | 说明 |
|------|------|
| ✅ 路径穿越防护 | 文件名正则校验 + resolve() 边界检查 |
| ✅ MIME + 扩展名双验证 | 文件上传双重类型检查 |
| ✅ 图片尺寸校验 | ≥10×10 像素 |
| ✅ 文件大小限制 | 默认 50MB |
| ✅ CORS 可配置 | 通过环境变量控制 |
| ✅ 异常统一处理 | 全局 exception_handler |
| ✅ XSS 防护 | 所有用户输入 textContent 转义 |
| ✅ API 超时 | 120s 超时 + 2 次重试 |
| ✅ 错误信息脱敏 | 不暴露内部异常细节 |
| ✅ API 密钥提醒 | 启动时提示使用环境变量 |
