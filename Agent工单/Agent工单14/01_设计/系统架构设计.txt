## 2. 技术选型

| 层次 | 技术 | 选型理由 |
|------|------|----------|
| **后端框架** | FastAPI | 高性能异步，自动生成 API 文档 |
| **VQA/MRG** | 千问 qwen-vl-plus | 多模态视觉理解，支持中文 |
| **RAG 推理** | DeepSeek deepseek-chat | 长上下文推理，高性价比 |
| **向量数据库** | ChromaDB | 轻量级，嵌入式部署 |
| **嵌入模型** | paraphrase-multilingual-MiniLM-L12-v2 | 多语言支持，384维 |
| **前端** | 原生 HTML/CSS/JS | 零依赖，即开即用 |
| **部署** | Docker + docker-compose | 一键部署，环境隔离 |

## 3. 数据流

### 3.1 VQA 流程
```
用户上传影像 → 选择VQA标签 → 输入问题 → 千问VL分析 →
返回：影像描述 + 诊断分析 + 鉴别诊断 + 建议
```

### 3.2 MRG 流程
```
用户上传影像 → 选择MRG标签 → 输入临床信息(可选) → 千问VL生成 →
返回：结构化报告（检查项目/技术/所见/印象/建议）
```

### 3.3 RAG 流程
```
用户输入问题 → ChromaDB 检索Top-K文档 → DeepSeek推理 →
返回：基于参考资料的回答 + 引用来源
```
