# 需求分析文档

**工单编号：** 人工智能 NLP-Agent 数字人项目-医疗智能体-影像分析 V1.0  
**创建人：** 王洪荣  
**创建日期：** 2025年4月26日

---

## 1. 项目概述

医疗智能体-影像分析系统，为患者用户提供挂号管理、健康咨询、影像分析功能的"健康助理 Agent"。

## 2. 用户故事

> 作为 **患者用户**，我想要 **一款能够实现挂号管理、健康咨询、影像分析的"健康助理 Agent"**，以便于 **实现影像分析功能**。

## 3. 功能需求

### 3.1 NLP 方向（本系统重点）

| 功能 | 描述 | 优先级 |
|------|------|--------|
| **VQA 视觉问答** | 上传医学影像，AI 分析后回答诊断问题 | P0 |
| **MRG 医疗报告生成** | 基于影像自动生成规范化诊断报告 | P0 |
| **RAG 检索增强生成** | 基于医学知识库检索并增强回答 | P0 |

### 3.2 CV 方向（非本系统重点）

| 功能 | 描述 |
|------|------|
| 医学成像分类 | 影像自动分类 |
| 目标检测 | 病灶检测定位 |
| B-Seg 分割 | 带边界框提示的分割 |
| G-Seg 分割 | 带文本提示的分割 |

## 4. 非功能需求

| 指标 | 目标值 |
|------|--------|
| 响应时间 | < 500ms |
| 检索精度 | ≥ 80% |
| 异常处理 | 能处理本场景下的异常输入 |
| 可用性 | 7×24 |

## 5. 技术约束

- 使用主流解决方案实现 Agent 功能
- 代码需包含工单编号注释
- 需产出 Docker 镜像文件
