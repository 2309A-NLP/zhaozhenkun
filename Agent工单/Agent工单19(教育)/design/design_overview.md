# 工单19 个性化学习推荐设计说明

## 1. 技术流程图（文字版 UML）
1. 学生登录或切换账号。
2. 系统读取学生历史画像、练习趋势、错题本与知识图谱。
3. 推荐引擎根据掌握度、前置依赖、错题记录生成学习路径。
4. 仪表盘展示学习画像、学习路径、今日任务、练习趋势与资源推荐。
5. 学生完成自适应练习后，系统更新知识掌握度。
6. 若答题错误，系统触发 AIGC 错题解析，写入错题本并生成变式题。
7. 系统重新计算学习画像并刷新后续推荐内容。

## 2. 接口设计
- `GET /`：仪表盘页面。
- `GET /api/dashboard?student_id=1`：获取首页聚合数据。
- `GET /api/questions?student_id=1`：获取自适应练习题。
- `POST /api/practice/submit`：提交练习答案并更新画像。
- `POST /api/portrait/import`：导入历史成绩并初始化画像。

## 3. 数据库设计
- `students`：学生基础信息。
- `knowledge_points`：知识点与前置依赖。
- `resources`：学习资源库。
- `assistant_faqs`：助教高频问题库。
- `questions`：练习与诊断题库。
- `student_mastery`：学生知识掌握度画像。
- `practice_records`：练习记录。
- `wrong_book`：错题本与 AIGC 解析。
- `trend_history`：练习趋势快照。

## 4. 前端设计原则
- 采用玻璃拟态卡片、渐变高光、深浅双主题。
- 所有推荐项均提供“为什么推荐”解释文案。
- 练习趋势采用单轴折线图，避免双轴误导。
- 错题本与推荐资源强调复盘闭环。
