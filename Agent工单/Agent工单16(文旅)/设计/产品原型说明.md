# 产品原型说明

> 工单编号：人工智能CV-AIGC-16-【必选】文旅Agent任务工单-需求分析与功能设计V1.1-20260306

## 一、文件位置

- 原型页面：`../研发/prototype/index.html`

## 二、原型用途

该原型用于展示《文旅创新智脑》AI智能体的核心交互界面，作为 Figma/Mastergo 的替代方案，方便在本地浏览器直接演示和交互操作。

## 三、原型包含页面

| 页面 | 功能 | 说明 |
|------|------|------|
| 🤖 数字人导览 | 数字人对话交互、快捷指令 | 模拟3D数字人导览场景，支持聊天和5大快捷指令 |
| 🔍 知识检索 | 多模态搜索、知识图谱 | 以图搜文/以文搜图/语音搜索入口，知识图谱关联展示 |
| 📊 管理后台 | 客流监控、设备管理、告警 | 仪表盘+柱状图，实时客流数据和IoT设备状态 |
| 💡 数据洞察 | NL2SQL问答、竞争力评估 | AI自然语言数据问答，18项指标竞争力评估 |
| 🎨 创意策划 | AIGC内容生成、活动策划 | 6种内容生成卡片，活动策划表单 |
| ⚡ 快捷指令 | 5大快捷指令入口 | 资源挖掘/场景创意/文化创新/数字营销/效益提升 |

## 四、原型特点

1. **6页面可切换**：左侧导航栏点击切换，无需多文件
2. **交互演示**：数字人对话模拟、快捷指令触发、搜索框交互
3. **数据可视化**：柱状图、统计卡片、排行榜、知识图谱节点
4. **响应式布局**：适配桌面和移动端
5. **零依赖**：纯HTML+CSS+JS，无需安装任何框架

## 五、如何运行

```bash
# 方式1：直接浏览器打开
start 研发/prototype/index.html

# 方式2：本地HTTP服务器（推荐）
cd 研发/prototype
python3 -m http.server 8080
# 然后浏览器打开 http://localhost:8080
```
