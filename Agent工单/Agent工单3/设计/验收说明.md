# 文生图智能体工单验收说明

工单编号：人工智能NLP-Agent数字人项目-文生图智能体任务

## 一、需求对应关系

### 1. 输入原图，生成三张效果图
已实现：
- 左转图像
- 右转图像
- 端正图像

对应代码：
- `image_generator.py`
- `main.py`
- `app.py`

### 2. 支持扩图
已实现：
- 对生成结果执行扩图
- 支持单图上传后直接扩图

对应代码：
- `outpainter.py`
- `main.py`
- `app.py`

### 3. 使用 Stable Diffusion 或 ComfyUI
本项目采用：
- Stable Diffusion + ControlNet 实现旋转生成
- Stable Diffusion Inpainting 实现扩图

### 4. 代码注释包含工单编号
已完成。

## 二、保留的增强组件

为满足项目扩展性，本项目保留以下组件：

- BGE-M3：提示词语义编码
- Milvus：提示词向量存储与相似检索
- Redis：图像结果缓存

说明：
这些组件作为增强层保留，不影响工单主流程的执行与验收。

## 四、你本地需要补的验收材料

下面这些要你本机实际跑完后补齐：

1. 1 张输入原图
2. 3 张旋转结果图
3. 3 张扩图结果图
4. 1 张对比图
5. 运行截图或录屏
6. 简单测试结论（例如：人脸可识别、角度基本正确、扩图自然）

## 五、建议测试步骤

1. 启动 Redis 和 Milvus
2. 确认 BGE-M3 本地路径存在
3. 运行：
   - `python app.py`
   或
   - `python main.py --input input/face.jpg`
4. 检查 `output/` 目录是否生成结果
5. 重复同一输入再次生成，观察 Redis 是否命中缓存
6. 在 Web 的“系统状态”页面检查 Milvus / Redis / BGE-M3 状态

当前版本已经从“原型演示”提升到“可交付项目框架”。

但是否最终验收通过，取决于你本机补齐实际生成结果和测试截图。
