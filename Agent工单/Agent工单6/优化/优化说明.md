# 优化记录 - AI Agent 智能体系统

## V2.2 (2026-06-23) — 深度修复：推理模型token预算与答案质量
### 根因分析
- **核心问题**: deepseek-v4-pro 是推理模型，内部推理消耗 max_tokens 预算，导致实际回答内容被截断或为空
- 意图识别 max_tokens=256 → JSON响应常被截断 → 工具路由失败
- 基金问答 max_tokens=512 → AI润色响应为空 → 回退到原始数据如 "300178 | 4.62"
- 招股书问答: 关键词"战略配售"在txt中不存在 → 段落提取失败 → 返回"未找到"

### 修复内容
#### 1. `tools.py` — _call_deepseek（API调用核心）
- 默认 max_tokens: 1024 → 2048
- 新增 reasoning_content 兜底提取（推理模型兼容）
- content为空时自动加大 max_tokens 重试
- 详细错误日志（含HTTP状态码）

#### 2. `agent_core.py` — 意图识别 & 通用对话
- recognize_intent max_tokens: 256 → 1024
- _general_chat max_tokens: 800 → 2048
- _general_chat 系统提示词改为要求完整回答（至少2-3句话）
- 新增 reasoning_content 兜底处理
- process_query 支持 pre_recognized_tool 参数避免重复API调用

#### 3. `tools.py` — 基金问答 tool_fund_qa
- SQL生成 max_tokens: 1024 → 4096
- AI润色 max_tokens: 512 → 2048
- 新增 _format_fund_answer() 模板兜底函数
  - AI润色失败时程序化格式化答案（不再回退原始数据）
  - 百分数自动格式化，小数精度保留
- SQL示例增加字段别名（如"涨跌幅(%)"）
- 错误时自动重试SQL修正

#### 4. `tools.py` — 招股书问答 tool_prospectus_qa
- 新增关键词扩展映射表（战略配售→配售/发行/网下配售等）
- 搜索词上限: 50→60，段落数上限: 30→40，最终保留: 6→8
- answer_kw_density 优先级调整（发行/配售/IPO相关词排在前面）
- RAG系统提示词强化（要求尽量提取相关信息，而非简单说"未找到"）
- RAG max_tokens: 1500 → 3072
- 上下文窗口: 8000 → 12000 字

#### 5. `main.py` — 路由优化
- 意图识别从两次调用合并为一次（先识别，传结果给process_query）
- demo匹配只在意图不明确时触发（工具匹配成功时跳过demo检查）
- demo回答 max_tokens: 500 → 1024
- 简化路由决策：demo结果 > 图片处理 > 工具路由

### 测试验证
- ✅ 基金债券查询: "景顺长城中短债债券C 20210331前三大持仓债券" → 列出21国开01/20农发清发01/20国信03，格式正确
- ✅ 股票涨跌幅: "20210715消费者服务涨跌幅最大" → "股票代码300178，涨跌幅4.62%"，自然语言完整
