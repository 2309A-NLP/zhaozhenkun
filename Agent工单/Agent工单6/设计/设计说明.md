# 设计说明 - AI Agent 智能体系统

## 架构

五合一智能体编排系统，统一调度5个领域工具。

### 系统架构

[浏览器] ←→ [Flask :5002] ←→ [Agent Core 意图识别] ←→ [5工具集]

- 入口层: Flask Web + 聊天UI (支持图片上传/粘贴)
- 意图层: DeepSeek v4-pro 意图识别 (5工具分类)
- 工具层: 记账本·日程提醒·文生图·基金问答·招股书RAG
- 数据层: SQLite + TXT文件 + 外部API

### 数据流

用户Query → sanitize → demo_qa.db匹配 → DeepSeek意图识别 → call_tool() → 工具执行 → 结果整合 → JSON响应

## 技术选型

| 组件 | 技术 | 理由 |
|------|------|------|
| 意图识别 | DeepSeek v4-pro | JSON结构化输出·中文理解 |
| 文生图 | DashScope qwen-image-edit-max | 真正图像生成/编辑API |
| 人脸旋转 | DashScope 图像编辑 | 保持身份·30°可控旋转 |
| 基金问答 | NL2SQL + SQLite | 1.46GB·10张表 |
| 招股书 | TF-IDF + RAG | 80TXT·公司名映射 |
| Web | Flask | 轻量·多工具路由 |
| 前端 | 原生HTML/CSS/JS | 暗色主题·图片上传 |
