# 测试说明 - AI Agent 智能体系统

## 测试用例

### 意图识别测试
- "记录今天的支出" → 记账本 ✓
- "明天下午3点开会" → 日程提醒 ✓
- "生成一张日落的图片" → 文生图 ✓
- "把这张照片里的人脸向左转" → 文生图(图片模式) ✓
- "景顺长城基金收益率" → 基金问答 ✓
- "湖南长远锂科发起人有哪些" → 招股书问答 ✓

### 工具功能测试
- 记账本: 添加/查询/删除记录
- 日程提醒: 添加/查询/删除日程
- 文生图: 文本生成图片 + 人脸旋转
- 基金问答: 涨跌幅/持仓/行业查询
- 招股书: 公司名映射+RAG检索
