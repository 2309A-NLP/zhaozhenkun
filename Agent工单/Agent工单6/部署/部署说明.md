# 部署说明 - AI Agent 智能体系统

## 环境要求
- Python 3.10+
- pip: flask, requests, dashscope, openai, scikit-learn
- 5个兄弟项目: Agent工单1-5
- 数据集: bs_challenge_financial_14b_dataset

## 快速启动

### 1. 安装依赖
pip install flask requests dashscope openai scikit-learn scipy

### 2. 启动服务
cd 研发
python main.py

### 3. 访问
浏览器打开 http://127.0.0.1:5002

## 运行模式
- Web模式: python run.py (端口5002)
- 支持图片上传/粘贴
- 支持多轮对话(session管理)
- 5个工具自动路由

## API端点
- POST /api/chat — 主对话接口
- GET /api/health — 健康检查
