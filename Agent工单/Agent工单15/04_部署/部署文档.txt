# 部署文档

**工单编号：** 人工智能 NLP-Agent 数字人项目-医疗智能体-影像分析 V1.0

---

## 1. 环境要求

| 组件 | 版本要求 |
|------|----------|
| Python | 3.11+ |
| Docker | 24.0+ |
| Docker Compose | 2.0+ |
| 内存 | ≥ 4GB |
| 磁盘 | ≥ 2GB |

## 2. 快速部署（Docker）

```bash
cd Agent工单13/04_部署
export QWEN_API_KEY="your-key"
export DEEPSEEK_API_KEY="your-key"
docker-compose up -d
```

访问 `http://localhost`

## 3. 开发部署

```bash
cd Agent工单13/02_研发/backend
pip install -r requirements.txt
python -m rag.init_knowledge    # 初始化知识库
python main.py                   # 启动服务
```

## 4. 环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| QWEN_API_KEY | (内置) | 千问 API 密钥 |
| DEEPSEEK_API_KEY | (内置) | DeepSeek API 密钥 |
| QWEN_VISION_MODEL | qwen-vl-plus | VQA/MRG 模型 |
| DEEPSEEK_MODEL | deepseek-chat | RAG 推理模型 |
| API_PORT | 8000 | 后端端口 |
| RAG_TOP_K | 5 | 检索文档数 |
| MAX_UPLOAD_SIZE_MB | 50 | 上传限制 |

## 5. 健康检查

```bash
curl http://localhost:8000/api/health
```
