# 性能优化方案

**工单编号：** 人工智能 NLP-Agent 数字人项目-医疗智能体-影像分析 V1.0

---

## 1. 当前性能瓶颈

| 瓶颈 | 影响 | 优先级 |
|------|------|--------|
| 外部 API 延迟 | VQA ~800ms, MRG ~3.7s, RAG ~1-13s | 🔴 |
| 嵌入模型首次加载 | 启动延迟 ~5s | 🟡 |
| ChromaDB 检索 | 19K 文档 ~10ms | 🟢 |

## 2. 优化方案

### 2.1 API 响应优化
- **缓存策略**：对相同图片+相同问题缓存结果（Redis/Memcached）
- **流式输出**：使用 SSE 流式返回，降低首字延迟感知
- **请求合并**：同一图片的多问题批量发送

### 2.2 嵌入模型优化
- **模型预热**：启动时预加载模型到内存
- **模型量化**：使用 ONNX 或 INT8 量化减小模型体积
- **GPU 加速**：CUDA 推理替代 CPU

### 2.3 ChromaDB 优化
- **索引优化**：调整 HNSW 参数（M, ef_construction）
- **分片存储**：按知识类别分 Collection
- **增量更新**：避免全量重建索引

### 2.4 前端优化
- **图片压缩**：上传前客户端压缩
- **懒加载**：历史记录分页
- **Service Worker**：离线缓存

## 3. 监控指标
