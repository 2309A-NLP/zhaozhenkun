# JSON 数据说明

这个项目的测试数据主要在下面几个文件里：

- `03_研发/data/courses.json`：课程列表
- `03_研发/data/students.json`：学生画像
- `03_研发/data/knowledge_base.json`：知识库片段
- `03_研发/data/sessions.json`：助教多轮对话历史
- `03_研发/data/artifacts.json`：每次场景运行结果记录
- `01_测试/场景测试样例.json`：给你直接照着输入的测试样例

## 你现在最推荐的测试方式

不要一上来自己乱输。
先打开 `01_测试/场景测试样例.json`，照着里面的字段在页面里填。
因为这些值是我按当前知识库关键词专门配好的，更容易命中结果。

## 哪些现象说明测试是对的

### 1. 智能备课
- 页面有正文输出
- 有 3 张卡片
- 正文里出现你输入的主题或补充要求

### 2. 智能助教
- 连续问两次都能出结果
- 第二次回答不是完全重复第一句
- `sessions.json` 会新增历史

### 3. 教学评估
- 文本输入时，正文里能看到你的学生答案
- 图片输入时，正文里能看到“识别图片”或演示模式提示
- 都会带 3 张评分卡

### 4. 个性化学习
- 能看到学生姓名和画像摘要
- 会出现学习风格、薄弱点、学习目标三张卡片
- 正文里能看到你的 focus 或补充要求

## 如果你只想最快验证一次

推荐按这个顺序：
1. 智能备课：`Python程序设计 + 循环结构`
2. 智能助教：`while循环 for循环 区别`
3. 教学评估：`学生答案：函数在x=0处不可导，因为左右导数不相等`
4. 个性化学习：学生选 `STU001`，聚焦填 `导数易错点纠偏`

这样四步基本就能确认系统主链路没问题。
