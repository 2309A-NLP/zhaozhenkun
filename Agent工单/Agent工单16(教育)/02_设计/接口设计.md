# 接口设计

## 1. 健康检查
- 路径：`GET /api/health`
- 作用：返回 DeepSeek / 千问 的文本与多模态状态。
- 返回字段：`deepseek_text`、`deepseek_vision`、`qwen_text`、`qwen_vision`

## 2. 统一场景接口
- 路径：`POST /api/scene/<scene>`
- 支持场景：`lesson`、`tutor`、`evaluation`、`personalization`
- 请求类型：`multipart/form-data` 或 `application/json`
- 公共参数：
  - `course`：课程名称
  - `topic`：主题
  - `message`：问题、备课需求或学生文本作答
  - `student_id`：学生编号
  - `task_name`：作业名称
  - `focus`：学习聚焦主题
  - `model_provider`：模型服务商，可选 `deepseek` 或 `qwen`
  - `image`：可选图片文件；不上传时直接走文本交互链路

## 3. 主要返回结构
```json
{
  "success": true,
  "data": {
    "scene": "lesson",
    "title": "高等数学 - 函数与导数基础 备课方案",
    "summary": "...",
    "model_provider": "deepseek",
    "input_mode": "text",
    "cards": [
      {"label": "教学目标", "value": "..."}
    ]
  }
}
```

## 4. 错误返回结构
```json
{
  "success": false,
  "message": "错误说明"
}
```
