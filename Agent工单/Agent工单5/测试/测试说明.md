# 测试说明 - 招股书PDF数据问答RAG

## 测试数据
- 题目: question.json (JSONL格式, 约100题招股书相关)
- 数据源: 80个PDF解析TXT文件 (44MB)
- 索引: 18,263 chunks, 20,000词汇, 144公司映射

## 测试方法

### 1. Web模式测试
python main.py
浏览器打开 http://127.0.0.1:5001
输入测试问题

### 2. CLI模式测试
python main.py --cli

### 3. 批量测试
python main.py --batch
输出: answer_result.jsonl
支持断点续传 (batch_progress.txt)

### 4. 调试诊断
python debug_test.py
输出: debug.log (详细检索诊断)

## 验收标准
- 公司名提取准确: 映射命中率>90%
- 检索覆盖: 分段检索>=40 chunks/问题
- API稳定性: 3次重试机制
- 答案质量: 引用原文·保留精确数字
