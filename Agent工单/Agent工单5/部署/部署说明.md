# 部署说明 - 招股书PDF数据问答RAG

## 环境要求
- Python 3.10+
- pip: flask, scikit-learn, scipy, requests, jieba
- 数据集: bs_challenge_financial_14b_dataset (80个TXT, 44MB)

## 快速开始

### 1. 安装依赖
pip install flask scikit-learn scipy requests

### 2. 下载数据集
git clone https://www.modelscope.cn/datasets/BJQW14B/bs_challenge_financial_14b_dataset.git

### 3. 构建索引(首次自动)
cd 研发
python main.py
首次启动需~54秒构建索引(后续<1秒)

### 4. 访问
浏览器打开 http://127.0.0.1:5001

## 运行模式
- Web: python main.py (端口5001)
- CLI: python main.py --cli  
- 批量: python main.py --batch (输出answer_result.jsonl)

## 索引缓存
- 位置: 研发/index_cache/ (170MB)
- 变更chunk_size等参数后自动重建
- sklearn版本变更自动重建
