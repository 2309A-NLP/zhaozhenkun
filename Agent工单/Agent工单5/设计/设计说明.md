# 设计说明 - 招股书PDF数据问答RAG

## 架构

RAG (检索增强生成) 问答系统，专为中国IPO招股说明书数据设计。

### 四层架构

[浏览器/CLI] ←→ [Flask Web / main.py] ←→ [RAG引擎] ←→ [80个TXT文件]

- 入口层: Flask Web UI + CLI交互 + 批量处理
- 检索层: TF-IDF + 公司名映射 + 分段检索
- 生成层: DeepSeek v4-pro RAG提示词工程
- 索引层: scikit-learn TfidfVectorizer + 磁盘缓存

### 核心数据流

用户问题 → sanitize_question() → extract_company_name() → company_map匹配 → 分段TF-IDF检索(每段取top8) → format_retrieved_context() → build_rag_prompt() → call_deepseek() → 答案

### 关键设计决策

- char_wb字符级ngram(2-4): 无需中文分词，适应任意专业术语
- 公司名优先检索: 先定位文件再检索，大幅提升精度
- 五段分段检索: 每段独立取top8，确保全文档覆盖
- 磁盘索引缓存: 170MB缓存，冷启动<0.6秒

## 技术选型

| 组件 | 技术 | 理由 |
|------|------|------|
| 检索 | TF-IDF char_wb ngram(2,4) | 轻量·无需GPU·中文友好 |
| 生成 | DeepSeek v4-pro | 长文本理解力强·API便捷 |
| Web | Flask | 轻量·模板引擎 |
| 索引 | scikit-learn + pickle | 标准工业方案·版本检测 |
| 前端 | 原生HTML/CSS/JS | 零依赖 |
