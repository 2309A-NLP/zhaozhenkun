# 工单18 部署说明

## 1. 环境准备
- Python 3.10+
- 浏览器需允许摄像头和麦克风权限
- 联网环境（需访问 jsDelivr CDN 加载 MediaPipe 和 SocketIO 前端库）
- 可选：本机安装 Tesseract 用于 OCR 降级
- 可选：本机安装 ffmpeg 用于视频关键帧抽取

## 2. 安装依赖
```bash
cd 研发/source
pip install -r ../../requirements.txt
```
或从项目根目录：
```bash
pip install -r requirements.txt
```

关键依赖说明：
- `flask-socketio` + `eventlet`：WebSocket 实时通信
- `edge-tts`：微软免费 TTS，高质量中文语音合成
- `paddlepaddle` + `paddleocr`：PDF 指定的 OCR 引擎
- `openai-whisper`：本地语音识别（base 模型）

## 3. 语音与 OCR 说明
- **TTS**：优先使用 edge-tts 生成真实中文语音 + 唇形同步数据
  - 如 edge-tts 不可用，自动降级为静音占位
- **ASR**：优先 Whisper base 模型本地识别，失败回退 SpeechRecognition
  - 依赖缺失时不阻塞项目启动
- **OCR**：优先 PaddleOCR，不可用时降级 Tesseract
- **摄像头识别**：前端 MediaPipe 提取关键点，后端基于规则识别行为

## 4. 配置环境变量
复制并编辑：
```bash
cp 部署/.env.example 部署/.env
# 编辑 .env 填入 DeepSeek 和 Qwen 的 API Key
```

## 5. 启动项目
```bash
python run.py
```

## 6. 打开页面
浏览器访问：
```
http://127.0.0.1:5050
```

## 7. 功能说明
### 输入方式
1. **文本输入**：直接在右侧输入框输入问题
2. **语音输入**：点击语音按钮开始录音，再次点击停止并发送
3. **图片上传**：点击图片按钮上传照片，自动识别讲解
4. **视频上传**：点击视频按钮上传视频，抽帧分析讲解
5. **摄像头实时互动**：左侧开启摄像头后，挥手/点赞/指向/微笑自动触发互动
6. **行为互动**：点击互动按钮手动选择行为类型

### 输出方式
1. **文本讲解**：对话区显示回答
2. **字幕输出**：底部字幕条实时同步
3. **TTS 语音播报**：真实中文语音合成
4. **唇形同步**：虚拟人物口型随语音同步开合
5. **路线推荐**：右侧推荐景点标签

### 虚拟人物交互
- 左侧大框展示虚拟导览人物（CSS 角色）
- 说话时口型自动同步（唇形同步）
- 光环随语音波动
- 右下角小窗显示摄像头实时画面
- 识别到动作时弹出提示

## 8. WebSocket 实时通信
项目已集成 SocketIO，支持：
- 实时文本对话（比 HTTP 更快）
- 实时语音流转写
- 实时图片分析
- 实时摄像头行为识别推送
- 断线自动重连

HTTP REST API 仍保留作为降级方案。
