# 工单18 测试用例设计

## 1. 健康检查
- 接口：GET /ping
- 预期：返回 ok=true

## 2. 创建会话
- 接口：POST /api/session/create
- 预期：返回 session_id

## 3. 文本问答
- 接口：POST /api/chat/text
- 输入：介绍主教学楼
- 预期：返回 answer、subtitle、references

## 4. 行为互动
- 接口：POST /api/chat/behavior
- 输入：wave
- 预期：返回 behavior=wave 和互动讲解

## 5. 图片讲解
- 接口：POST /api/chat/image
- 输入：上传一张图片
- 预期：返回 image_summary、ocr_text、answer

## 6. 多语言
- 接口：POST /api/chat/text
- 输入：language=en
- 预期：返回英文讲解或英文风格结果
