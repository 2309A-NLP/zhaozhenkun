# 工单18 语音与视频增强说明

## 一、本次新增目标
继续按照PDF要求补齐：
1. 视频输入不只是入口，而是具备基础分析讲解链路
2. 语音输入不只是占位，而是具备更真实的ASR入口

## 二、语音增强
### 已完成
1. 新增本地Whisper优先识别
2. Whisper失败后，再回退SpeechRecognition备用链路
3. 再把转写文本送入导览问答链路

### 当前边界
1. 当前优先走本地Whisper base模型
2. 失败时会回退备用识别
3. 还未做麦克风实时采集识别，只做语音文件输入识别

## 三、视频增强
### 已完成
1. 后端新增多帧视频分析服务
2. 使用 `ffmpeg` 从视频抽取多张代表帧
3. 对多帧执行图片理解
4. 对多帧执行OCR
5. 再结合知识库生成视频讲解结果

### 当前边界
1. 当前是多帧摘要分析，不是全程逐帧跟踪
2. 还没接YOLO视频检测/跟踪
3. 但已经从“只有视频上传入口”升级为“视频可抽帧、可分析、可讲解”

## 四、意义
现在项目在语音、图片、视频、摄像头四类输入上，都已经有了真实链路，不再只是页面层演示。
