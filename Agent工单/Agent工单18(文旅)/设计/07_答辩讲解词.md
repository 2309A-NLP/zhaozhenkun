# 工单18 答辩讲解词

## 一、开场讲解
各位老师好，我本次汇报的项目名称是《文旅智能体-智能导览与互动体验》。这个项目是基于文旅场景构建的一个多模态智能导览系统，目标是让游客不仅能“看景点”，还可以通过文本提问、上传图片、触发互动行为等方式，获得更自然、更智能的导览体验。

## 二、项目背景
传统文旅导览通常存在几个问题：
1. 讲解方式单一，通常是固定文本或固定语音播报。
2. 缺少实时互动，游客的问题无法灵活响应。
3. 无法充分利用图片、行为、字幕、多语言等多模态能力。

所以我这次项目的目标，就是把数字人导览、大模型问答、多模态识别和知识库检索结合起来，做一个更接近真实应用场景的智能导览系统。

## 三、项目功能介绍
我的项目主要实现了以下几个核心功能：

### 1. 文本问答导览
游客可以直接输入问题，例如“请介绍这里的历史文化”或者“推荐一条参观路线”，系统会结合知识库检索和大模型能力，返回讲解内容和推荐路线。

### 2. 图片上传讲解
游客可以上传一张图片，比如景点照片、展板照片、文物图片、植物图片。系统会调用多模态模型分析图片内容，再结合 OCR 文字提取和本地知识库生成详细讲解。

### 3. 行为互动
系统支持挥手、点赞、指向、微笑等行为事件输入。当前版本采用行为标签方式做演示，后续可以直接扩展为摄像头实时识别。数字人会根据游客行为调整互动方式，并给出景点推荐。

### 4. 多语言与无障碍支持
系统支持中英文切换，并且每一次回答都会同步输出字幕，满足无障碍展示需求。

## 四、项目技术架构
项目整体分为前端、后端、知识库和模型接入四个部分。

### 1. 前端层
前端采用独立 HTML、CSS、JavaScript 实现，主要负责：
- 数字人导览界面展示
- 文本提问
- 图片上传
- 行为互动触发
- 字幕展示
- 推荐景点展示

### 2. 后端层
后端使用 Flask 搭建，负责：
- 会话管理
- 接口分发
- 文本问答处理
- 图片讲解处理
- 行为互动处理
- 知识库检索
- 模型调用

### 3. 知识库层
当前版本采用本地 JSON 文旅知识库，内容包括景点名称、类别、关键词、简介和详细说明。系统会根据游客问题、图片摘要、OCR 结果或行为说明进行轻量级检索，实现 RAG 增强效果。

### 4. 模型层
- DeepSeek：负责文本生成和讲解组织
- 千问兼容多模态接口：负责图片内容理解
- OCR：当前版本是轻量占位实现，便于后续替换成 PaddleOCR 等真实模型

## 五、项目亮点
我认为这个项目有四个亮点：

1. 不只是一个聊天系统，而是围绕文旅场景做的完整导览链路。
2. 支持文本、图片、行为三类核心输入，体现多模态特征。
3. 同时具备知识库检索和大模型生成，不是纯大模型裸回答。
4. 工程结构规范，适合作为工单交付项目和后续扩展基础。
