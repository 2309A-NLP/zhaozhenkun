# 工单18 图片识别与OCR增强说明

## 一、本次增强目标
按照PDF中“游客上传或拍摄照片，数字人自动识别图片内容并进行讲解”的要求，补强图片讲解链路。

## 二、本次已增强内容
1. OCR从原来的占位实现升级为真实OCR
   - 使用本机 `tesseract`
   - 使用 `pytesseract + OpenCV + PIL`
   - 支持对展板、碑文、指示牌等图像做真实文字提取

2. 图片理解增强
   - 使用更细化的视觉提示词
   - 提取主体对象、类别、文字线索、场景环境、旅游相关信息

3. 图片讲解增强
   - 先解释图片里看到了什么
   - 再结合OCR结果和知识库生成导览讲解
   - 同步给出推荐路线

## 三、当前实现方式
1. 前端上传图片
2. 后端先做图片校验
3. 调用多模态模型获取图片摘要
4. 调用真实OCR提取文字
5. 用图片摘要 + OCR文本做知识库检索
6. 最终生成导览讲解结果

## 四、当前边界
1. 目前OCR已是真OCR
2. 图像分类/检测/分割仍未接YOLO或SAM类模型
3. 图片讲解主链路已明显比之前的占位版更接近PDF要求
