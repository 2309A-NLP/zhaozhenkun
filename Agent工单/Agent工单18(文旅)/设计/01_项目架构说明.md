# 工单18 文旅智能体项目架构说明 V2.0

## 一、项目目标
根据《人工智能CV-AIGC-18-文旅Agent任务工单-智能导览与互动体验V1.1-20260306.pdf》实现完整的"文旅智能导览与互动体验"项目。

## 二、技术架构升级（V2.0）
### 通信层
- **WebSocket (SocketIO)**：实时双向通信，替代 HTTP 轮询
- **HTTP REST API**：保留作为降级方案

### 前端层
- 现代化暗色玻璃态 UI
- CSS 虚拟人物角色 + 唇形同步动画
- Web Audio API 驱动口型（AnalyserNode 振幅分析）
- MediaPipe 前端模型（Pose + Hands + FaceMesh）
- WebRTC 摄像头采集 + requestAnimationFrame 实时循环
- MediaRecorder API 麦克风流式录制

### 智能体服务层
- Flask + SocketIO 服务
- Agent 任务调度模块（工具调用 + LLM 规划）
- 会话管理（UUID + 上下文记忆）

### AI 模型层
- LLM：DeepSeek Chat（文本生成）
- 多模态：Qwen VL（图片/视频理解）
- TTS：edge-tts（微软免费高质量中文语音 + 唇形同步时间戳）
- ASR：Whisper base（本地离线识别）
- OCR：PaddleOCR（优先）+ Tesseract（降级）
- CV 行为识别：后端规则 + 前端 MediaPipe 关键点
