# 工单18 接口设计 V2.0

## 一、REST API

### 1. GET /ping
用途：健康检查
返回：`{"ok": true, "message": "service alive"}`

### 2. POST /api/session/create
用途：创建会话
返回：`{"ok": true, "session_id": "uuid", "created_at": "ISO时间"}`

### 3. POST /api/chat/text
用途：文本导览问答
请求：`{"session_id": "uuid", "question": "...", "language": "zh"}`
返回：`{"ok": true, "answer": "...", "subtitle": "...", "references": [...], "audio_base64": "...", "lip_sync": [...], "route_tip": "..."}`

### 4. POST /api/chat/audio
用途：语音文件问答（multipart/form-data）
返回：`{"ok": true, "transcript": "...", "answer": "...", "audio_base64": "..."}`

### 5. POST /api/chat/image
用途：图片识别讲解（multipart/form-data）
返回：`{"ok": true, "image_summary": "...", "ocr_text": "...", "answer": "...", "audio_base64": "..."}`

### 6. POST /api/chat/video
用途：视频讲解（multipart/form-data）
返回：`{"ok": true, "video_summary": "...", "ocr_text": "...", "answer": "..."}`

### 7. POST /api/chat/behavior
用途：行为感知互动
请求：`{"session_id": "uuid", "behavior": "wave", "language": "zh"}`
返回：`{"ok": true, "answer": "...", "behavior": "wave"}`

### 8. POST /api/realtime/behavior
用途：实时摄像头行为识别
请求：`{"session_id": "uuid", "pose": {...}, "hands": [...], "face": {...}}`
返回：`{"ok": true, "detected": true/false, "behavior": "wave", "confidence": 0.88, "answer": "..."}`

### 9. GET /api/knowledge/spots
用途：获取景点列表
返回：`{"ok": true, "spots": [...]}`

### 10. GET /api/digital-human/config
用途：获取数字人配置
返回：`{"ok": true, "config": {...}}`

### 11. POST /api/agent/task
用途：Agent 任务调度
请求：`{"task": "推荐最佳游览路线", "language": "zh"}`
返回：`{"ok": true, "answer": "...", "steps": [...], "tool_calls": N}`

## 二、WebSocket 事件（SocketIO）

### 客户端 → 服务端
| 事件 | 用途 | 数据 |
|------|------|------|
| `chat:text` | 文本对话 | `{session_id, question, language}` |
| `chat:audio` | 语音流 | `{session_id, audio: base64, format: "webm"}` |
| `chat:image` | 图片分析 | `{session_id, image: base64, question, language}` |
| `realtime:frame` | 摄像头帧 | `{session_id, payload: {pose, hands, face}}` |
| `tts:speak` | 单独TTS请求 | `{text: "..."}` |

### 服务端 → 客户端
| 事件 | 用途 | 数据 |
|------|------|------|
| `connected` | 连接确认 | `{status: "ok"}` |
| `chat:response` | 对话回复 | `{type, answer, subtitle, audio_base64, lip_sync, references}` |
| `chat:transcript` | 语音转写 | `{transcript: "..."}` |
| `chat:error` | 错误通知 | `{error: "..."}` |
| `realtime:result` | 行为识别结果 | `{detected, behavior, confidence, answer}` |
| `tts:audio` | TTS音频 | `{audio_base64, lip_sync, duration}` |

## 三、错误规范
统一返回：`{"ok": false, "error": "错误信息"}`
