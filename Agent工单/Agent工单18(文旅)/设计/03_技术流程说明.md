## 4. 实时行为识别数据流图 (Data Flow)

```
摄像头帧(640x480)
     │
     ├──→ YOLO11n 人体检测 + ByteTrack 跟踪
     │       │
     │       ├──→ 人体框(L/C/R分区) → 帧差法 → 运动占比
     │       │       ├──→ 单侧主导(>48%)       → "point" 指向
     │       │       ├──→ 中央集中(>55%)       → "thumbs_up" 点赞
     │       │       ├──→ 分布运动(中央+侧边)  → "wave" 挥手
     │       │       └──→ 面部运动累积(3帧+)   → "smile" 微笑
     │       │
     │       └──→ 行为触发 → handle_behavior_chat() → TTS回复 → 唇形同步
     │
     └──→ MediaPipe Pose/Hands/FaceMesh (前端)
             ├──→ 手腕高于肩膀       → 挥手
             ├──→ 手部点赞手势标签   → 点赞
             ├──→ 手臂横伸           → 指向
             └──→ 嘴角宽度+嘴开合    → 微笑
```

## 6. 关键数据流

| 输入 | 处理链路 | 输出 |
|------|---------|------|
| 文本问题 | 向量RAG语义检索 → DeepSeek生成 → TTS合成 | 语音+字幕+唇形 |
| 图片 | CLIP分类 + FastSAM分割 + PaddleOCR + 向量RAG + DeepSeek | 分类+分割+讲解+语音 |
| 视频 | ffmpeg抽帧 → 多帧分类+OCR → 向量RAG → DeepSeek | 视频讲解+语音 |
| 摄像头帧 | YOLO检测+ByteTrack跟踪 + 分区帧差法 → 行为识别 | 行为标签+互动回复 |
| 语音 | Whisper ASR → 文本 → 向量RAG → DeepSeek → TTS | 语音回复+字幕 |
