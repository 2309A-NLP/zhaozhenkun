# 工单18 知识库构建说明

## 1. 当前知识库形式
当前版本使用 `研发/data/spots.json` 作为轻量文旅知识库，适合演示项目和本地快速联调。

## 2. 知识字段
- name：景点名称
- category：景点类别
- keywords：检索关键词
- summary：简介
- details：详细说明

## 3. 检索方式
当前版本采用关键词召回，按问题、图片摘要、OCR结果、行为说明进行匹配。
