# 工单18 项目介绍词

大家好，我这次完成的项目是《文旅智能体-智能导览与互动体验》项目。

这个项目的核心目标，是围绕文旅场景做一个可以交互、可以讲解、可以识别图片、还能根据游客行为进行互动反馈的智能导览系统。传统导览更多是静态讲解或者固定播报，而我这次做的版本，把数字人导览、多模态输入、知识库检索和大模型生成结合在了一起，让系统具备更强的互动性和演示价值。

我的项目整体采用前后端分离思路来实现。前端部分主要负责游客交互界面展示，包括数字人导览区、问答区、图片上传区、行为互动区以及字幕展示区。后端部分基于 Flask 搭建，负责接收用户输入、进行会话管理、调用知识库检索、调用大模型生成讲解结果，并将最终答案返回给前端。

在功能上，这个项目主要实现了四类核心能力。
第一类是文本问答导览。游客可以直接输入问题，比如询问景点历史、建筑特色、文化背景，系统会结合本地知识库和大模型生成自然语言讲解。
第二类是图片讲解。游客可以上传一张景物、展板、文物或者植物图片，系统会通过多模态接口分析图片内容，再结合 OCR 和知识库生成讲解结果。
第三类是行为互动。系统支持以行为标签方式模拟游客挥手、点赞、指向、微笑等动作，再由数字人给出对应的互动反馈和景点推荐。
第四类是多语言和无障碍支持。系统支持中英文切换，并且每次回答都会同步输出字幕，方便展示无障碍能力。

在技术方案上，我使用了 DeepSeek 作为文本生成模型，使用千问兼容接口来承接图片多模态理解，同时结合本地 JSON 知识库做轻量级 RAG 检索增强。这样做的好处是，一方面能满足工单里“智能导览与互动体验”的业务目标，另一方面项目也更适合作为一个可运行、可演示、可扩展的交付版本。

在工程结构上，我严格按照五分类目录进行整理，分别是设计、研发、测试、优化、部署。这样做的意义是让项目不仅能跑，而且适合交付、适合检查、适合答辩。与此同时，我还按照要求控制了每个 Python 文件不超过 300 行，并在代码中加入了中文注释和文件功能说明，保证代码规范达标。

总的来说，这个项目的亮点不只是“做了一个聊天页面”，而是围绕文旅导览场景，把文本问答、图片讲解、行为互动、知识库检索和大模型生成真正串成了一条完整链路。它已经具备一个文旅智能导览系统的核心雏形，后续还可以继续升级到实时摄像头识别、真实语音播报、数字人口型同步以及更完整的多模态 RAG 系统。
