# 工单18 实时摄像头交互说明

## 一、实现目标
本次新增的是“真实摄像头实时识别版”最小可运行方案，用于满足工单中“通过摄像头实时捕捉游客的手势、表情、动作，实现看得见的互动”这一要求。

## 二、当前实现方式
### 前端
1. 使用浏览器 `getUserMedia` 打开摄像头
2. 使用 MediaPipe 前端模型实时提取：
   - Pose 人体关键点
   - Hands 手部关键点
   - FaceMesh 人脸关键点
3. 使用 `requestAnimationFrame` 持续循环识别，不再依赖粗糙定时器
4. 周期性把关键点结果发送到后端接口 `/api/realtime/behavior`

### 后端
1. 接收前端关键点JSON
2. 基于放宽后的阈值规则识别：
   - 挥手
   - 点赞
   - 指向
   - 微笑
3. 一旦识别到动作，自动触发数字人互动讲解链路

## 三、本次修复点
1. 修掉了前端只定时触发、结果不稳定的问题，改为更连续的实时循环
2. 修掉了前端关键点缺失时可能传 `undefined` 的问题，改成稳定默认值
3. 下调了识别阈值，让普通挥手更容易触发
4. 前端新增实时识别提示，告诉用户当前有没有识别到动作

## 四、使用建议
1. 先创建会话
2. 开启摄像头
3. 开启实时识别
4. 保证上半身和手臂完整出现在镜头里
5. 挥手时尽量把手抬到肩膀附近或以上，并向身体外侧展开

## 五、当前边界
1. 当前是基于关键点规则识别，不是YOLO重模型识别
2. 当前更适合演示“实时可见互动”能力
3. 如果后续要继续增强，可升级为：
   - YOLOv8 Pose
   - 专门手势识别模型
   - 表情分类模型
   - WebSocket 长连接
