工单18 智能助教系统设计
1. 用户角色：教师、学生。
2. 知识库：公共知识库 + 用户私有知识库。
3. 解析链路：文本/表格/课件/PDF/图片先统一转为结构化 chunks，并保留 page、sheet、slide、chunk 等定位信息。
4. 检索链路：公私库可访问资源过滤 -> 关键词召回 -> 轻量语义召回 -> RRF 融合 -> 问答生成。
5. 模型接入：DeepSeek / 千问，前端按钮切换，图片解析优先复用当前提供商。
6. 输出：答案 + 结构化引用 + 多模态标签 + 资源详情展示。
7. 安全策略：登录响应脱敏，不向前端返回密码；状态文件使用单锁原子写入，降低并发丢写风险。
