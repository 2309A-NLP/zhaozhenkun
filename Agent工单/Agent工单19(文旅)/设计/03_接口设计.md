# 工单19接口设计

## 1. 健康检查
- `GET /api/health`
- 返回服务名称与存活状态。

## 2. 创建会话
- `POST /api/session/create`
- 返回 `session_id` 与创建时间。

## 3. 生成策划方案
- `POST /api/plan/generate`
- 请求字段：`theme`、`city`、`audience`、`duration`、`budget`、`keywords`、`session_id`
- 返回字段：`brief`、`positioning`、`highlights`、`activities`、`knowledge`、`risk_tips`

## 4. 生成传播内容
- `POST /api/content/generate`
- 请求字段同上。
- 返回字段：`title`、`highlights`、`social_posts`、`video_script`、`host_lines`

## 5. 生成路线推荐
- `POST /api/recommend/generate`
- 请求字段同上。
- 返回字段：`route_name`、`route_steps`、`fit_people`、`tips`、`knowledge`

## 6. 生成 PPT 大纲
- `POST /api/export/ppt-outline`
- 请求字段同上。
- 返回字段：`topic`、`slides`

## 7. 生成流程图
- `POST /api/export/flowchart`
- 请求字段同上。
- 返回字段：`topic`、`mermaid`

## 8. 查询会话快照
- `GET /api/session/<session_id>`
- 返回会话基础信息与消息列表。
