# 工单19需求拆解

## 一、项目目标
- 面向文旅场景构建创意策划与内容生成 Agent。
- 支持策划方案、传播文案、路线推荐、PPT 大纲、流程图输出。
- 结合本地文旅知识库增强结果可信度与在地化表达。

## 二、功能范围
- 策划生成：围绕主题、城市、人群、预算生成完整策划框架。
- 内容生成：输出标题、亮点文案、社交文案、短视频脚本、口播词。
- 推荐生成：输出体验路线、时间安排、适合人群、出行提示。
- 导出生成：输出 PPT 汇报大纲与 Mermaid 流程图。
- 会话能力：支持创建会话并查看快照。

## 三、目录与规范要求
- 按 `部署`、`测试`、`设计`、`研发`、`优化` 分目录。
- 每个 Python 文件不超过 300 行。
- 每个 Python 文件开头写明文件功能。
- Python 代码逐行补充中文注释。

## 四、交付物
- Flask 后端源码。
- 单页前端页面。
- 本地知识库样例数据。
- 需求、架构、接口、测试、部署、优化文档。

## 五、验收映射
- 页面可访问。
- `/api/health` 正常。
- 能生成策划、内容、推荐、PPT 大纲、流程图。
- 测试文档记录至少 3 条业务链路。
