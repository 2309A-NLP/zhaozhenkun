# 工单19架构设计

## 一、总体结构
- 前端：单页 HTML + 原生 JavaScript。
- 后端：Flask 应用工厂 + Blueprint 路由。
- 服务层：按会话、Prompt、策划、内容、知识、导出拆分。
- 数据层：本地 JSON 文旅知识库。

## 二、核心流程
1. 用户输入主题、城市、人群、时长、预算、关键词。
2. 后端将输入整理为标准 brief。
3. 知识服务根据 brief 做轻量检索。
4. 策划服务和内容服务生成结构化结果。
5. 导出服务把结果整理为 PPT 大纲或 Mermaid 流程图。
6. 前端展示结果。

## 三、模块说明
- `app.py`：应用创建与启动。
- `config/settings.py`：配置读取。
- `routes/page_routes.py`：页面路由。
- `routes/api_routes.py`：业务接口路由。
- `services/session_service.py`：会话管理。
- `services/prompt_service.py`：提示词组织。
- `services/planner_service.py`：策划框架生成。
- `services/content_service.py`：内容与推荐生成。
- `services/knowledge_service.py`：知识检索。
- `services/export_service.py`：导出结果生成。

## 四、扩展方向
- 接入真实 LLM 接口。
- 接入真实 PPT 生成器。
- 增加多语言、图片生成、分享发布能力。
