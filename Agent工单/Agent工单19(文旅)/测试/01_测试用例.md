# 工单19测试用例

## 一、基础接口测试
1. 访问首页，确认页面正常打开。
2. 调用 `GET /api/health`，确认返回 `ok=true`。
3. 调用 `POST /api/session/create`，确认返回会话编号。

## 二、业务链路测试
### 用例1：故宫夜游活动策划
- 输入：主题=`故宫夜游`，城市=`北京`，人群=`年轻游客`
- 预期：返回完整策划定位、亮点、活动流程、知识增强内容

### 用例2：非遗短视频脚本
- 输入：主题=`非遗手作体验`，城市=`黄山`，人群=`亲子家庭`
- 预期：返回标题、亮点文案、社交文案、视频脚本、口播词

### 用例3：暑期亲子路线推荐
- 输入：主题=`暑期亲子研学`，城市=`西安`，人群=`亲子家庭`
- 预期：返回路线名称、路线步骤、适合人群、提示信息

## 三、导出与纪念内容测试
1. 生成 PPT 大纲，确认 `slides` 结构完整。
2. 生成流程图，确认返回 Mermaid 文本。
3. 生成纪念内容，确认返回明信片寄语、纪念海报标题、电子相册封面、虚拟合影提示词与分享文案。
4. 下载完整方案包，确认成功生成 `.md` 文件并包含策划、内容、推荐、纪念内容与流程图。
5. 切换地区与景点，确认主视觉图片、城市输入框、景点卡片与生成内容同步切换。
6. 点击“定位并规划”，确认页面成功获取当前位置并展示到当前景点的距离、时长与路线步骤。
7. 切换到其他地区或景点后，确认地图中心与路线结果同步刷新。
8. 在未配置 DeepSeek 密钥或模型网络不可达时，确认策划、内容、推荐、纪念与导出接口会自动回退，不会长时间卡死。

## 四、异常测试
1. 空 JSON 请求，确认系统使用默认值而不报错。
2. 不存在的 `session_id` 查询，确认返回空消息结构。
3. 浏览器拒绝定位权限时，确认页面提示用户重新授权，而不会导致其他生成功能不可用。
