# 实时数字人交互系统

工单编号: 人工智能NLP-Agent数字人项目-实时数字人交互任务

## 快速开始

### 1. 设置环境变量(必须)
```bash
export DEEPSEEK_API_KEY=你的API-KEY
```

### 2. 安装依赖
```bash
cd "Agent工单8"
pip install -r requirements.txt
```

### 3. 检查环境
```bash
python run.py --config config.yaml --check
```

### 4. 启动 Web 服务
```bash
python run.py --config config.yaml --port 8002
```
浏览器打开: http://localhost:8002

### 5. 离线测试(音频→唇形同步视频)
```bash
python run.py --offline --input test.wav --output output.mp4
```

## 当前主链路
```text
麦克风/WebSocket 二进制音频 → Whisper ASR → LLM → EdgeTTS/CosyVoice →
Mel特征提取 → LipSync → 帧合成 → MJPEG/RTMP 输出
```

## 项目结构
```text
src/core/      # 会话管理、管线编排、打断检测、性能埋点辅助
src/asr/       # Whisper语音识别(CPU)
src/llm/       # DeepSeek/OpenAI兼容接口客户端(流式)
src/tts/       # TTS引擎(EdgeTTS + CosyVoice可选)
src/audio/     # Mel频谱特征提取
src/lipsync/   # 唇形同步引擎与模型接入
src/video/     # 帧合成、人脸检测、空闲视频播放器
src/output/    # WebRTC / RTMP 输出对象
src/api/       # FastAPI + REST + WebSocket
src/utils/     # 日志、音频工具、FFmpeg、性能追踪
static/        # Web 前端页面
```

## API
| 端点 | 方法 | 说明 |
|------|------|------|
| /api/v1/session/create | POST | 创建会话 |
| /api/v1/session/{id}/text | POST | 文本对话 |
| /api/v1/session/{id}/interrupt | POST | 打断 |
| /api/v1/session/{id}/settings | PUT | 更新会话设置(语言/场景/提示词) |
| /api/v1/session/{id}/settings | GET | 获取会话设置 |
| /api/v1/session/{id}/metrics | GET | 获取性能指标(延迟/帧率/SLA) |
| /api/v1/session/{id}/audio | GET | 获取最近一次 TTS 音频 |
| /api/v1/session/{id}/video_stream | GET | MJPEG 视频流 |
| /api/v1/session/{id}/rtmp/start | POST | 启动 RTMP 推流 |
| /api/v1/session/{id}/rtmp/stop | POST | 停止 RTMP 推流 |
| /api/v1/voice/clone | POST | 上传参考音频作为声音克隆样本 |
| /api/v1/health | GET | 健康检查 |

## 说明
- 当前浏览器主交互链路以 `WebSocket + MJPEG + 音频接口` 为主。
- WebRTC 真实低延迟音视频协商尚未完整实现，不建议在本轮验收中按”完整 WebRTC 通话”口径声明。
- MuseTalk、ER-NeRF 目前属于预留模型接入口，未纳入本轮”完全兼容”承诺。
- **唇形同步默认使用 SimpleLipSync** (基于音频能量实时驱动嘴部 cv2.remap 变形，零延迟)。
  SadTalker 因推理耗时 ~9s/次 且缓存逻辑存在 bug（新音频被旧帧覆盖），已切换为可选，可通过 config.yaml `lipsync.model: sadtalker` 恢复。
