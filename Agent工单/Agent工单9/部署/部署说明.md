# 部署说明 - AI Agent 智能体系统 (含语音管线)

## 环境要求
- Python 3.10+
- pip: flask, requests, dashscope, openai, scikit-learn
- 5个兄弟项目: Agent工单1-5
- 数据集: bs_challenge_financial_14b_dataset

### 语音管线依赖 (工单09新增)
- FunASR: `pip install funasr modelscope` (语音识别)
- GPT-SoVITS: 独立部署的服务 (语音合成+声音克隆)
- liveTalking: GitHub开源数字人框架 (视频生成)
- EdgeTTS: `pip install edge-tts` (TTS自动回退)
- librosa + soundfile: `pip install librosa soundfile` (音频处理)

## 运行模式
- Web模式: `python run.py` (端口5002)
- 支持文本对话 / 图片上传粘贴 / 🎤语音输入
- 支持多轮对话(session管理)
- 5个工具自动路由
- TTS语音合成（GPT-SoVITS优先，EdgeTTS自动回退）

## API端点
| 端点 | 方法 | 说明 |
|------|------|------|
| POST /api/chat | 文本对话 | 主对话接口(文本+图片) |
| POST /api/voice/chat | 语音对话 | 上传音频→ASR→Agent→TTS |
| POST /api/tts | 文本转语音 | 支持voice参数进行声音克隆 |
| POST /api/voice/clone | 声音克隆 | 上传参考音频注册声音 |
| GET /api/voice/status | 语音管线状态 | ASR/TTS/DH状态检查 |
| GET /api/health | 健康检查 | 含ASR/TTS/DH状态 |

## 语音管线
```
麦克风 → FunASR(SenseVoiceSmall) → 文本 → Agent(DeepSeek) → 回复 → GPT-SoVITS → 音频输出
                                                                       ↓ (自动回退)
                                                                   EdgeTTS
```
对应工单: 人工智能NLP-Agent数字人项目-数字人与智能体的集成任务
