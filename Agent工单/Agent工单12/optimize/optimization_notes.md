# 医疗健康咨询 Agent — 优化建议

## 性能优化

1. **LLM 缓存**: 对高频问题缓存 LLM 答案，减少 API 调用 (当前 ~3s/次)
2. **Neo4j 连接池**: 当前使用默认连接池，可调优 max_connection_pool_size
3. **图谱查询批量化**: 多个 Cypher 合并为一条减少往返
4. **异步化**: entity_extractor 和 cypher_generator 可并行执行
5. **模型蒸馏**: 用小模型 (如 qwen2.5:1.5b) 做实体抽取，减少延迟

## 功能增强

1. **症状 ↔ 疾病 反向查询**: 当前仅支持 疾病→属性，可增加 症状→可能的疾病
2. **多轮对话**: 支持追问和上下文记忆
3. **语音输入**: 集成 ASR (参考 Agent工单8 的 Whisper 方案)
4. **药品交互检查**: 多药物同时查询时检查相互作用
5. **个性化推荐**: 结合用户年龄/性别/病史做精准推荐

## 运维优化

1. **Prometheus 监控**: 集成 prometheus-fastapi-instrumentator
2. **日志聚合**: 结构化日志 + ELK
3. **API 限流**: 添加 rate limiting 防止滥用
4. **缓存层**: Redis 缓存热点查询结果
5. **A/B 测试框架**: 对比不同 LLM 后端的回答质量
