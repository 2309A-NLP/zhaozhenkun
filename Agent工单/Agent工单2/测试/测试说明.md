# 测试说明

## 建议测试语句（对应工单验收标准）

1. 添加日程：下午5点开会
2. 每天早上8点提醒我起床
3. 我今天的日程有哪些？
4. 修改日程1 时间改为下午3点
5. 确认修改
6. 把日程2改成每天上午8点买咖啡
7. 确认修改
8. 删除日程1
9. 确认删除
10. 取消日程2
11. 每周一上午9点开例会
12. 明天上午10点提醒我交报告

## 预期结果

- 第 1 条：解析出时间 17:00，事项"开会"，写入数据库。
- 第 2 条：解析出时间 08:00，事项"起床"，repeat_rule=daily。
- 第 3 条：列出当天所有启用的日程。
- 第 4 条：展示修改前后对比，提示确认修改。
- 第 5 条：执行修改，回复"已修改日程 #1（开会）：时间已更新为「15:00」"。
- 第 6 条：展示修改前后对比（时间、内容、重复规则都要改）。
- 第 7 条：执行修改，回复修改后的新内容。
- 第 8 条：展示日程1的内容，提示"若确认删除请回复确认删除"。
- 第 9 条：执行删除，回复"已经删除日程 1，删除的日程内容是：17:00 开会"。
- 第 10 条：同删除流程。
- 第 11 条：解析出 repeat_rule=weekly，repeat_detail=Monday。
- 第 12 条：解析出明天日期。

## 自动化测试

运行 `python 测试/test_app.py` 可自动执行上述测试用例并输出结果。

## 验收标准检查

| 验收项 | 说明 |
|--------|------|
| 数据库调用率 | 100%，每次增删查操作均走 SQLite |
| 存储准确性 | 字段正确写入，可通过 GET /api/records 查验 |
| 完整性引导 | 缺少时间/事项时给出明确提示 |
| 复杂理解 | 支持"下午5点"、"早上8点"、"每天"、"每周一"等口语化表达 |
| 流程完善性 | 删除前二次确认，防止误删 |
| 提醒功能 | 后台调度器每分钟轮询，到期触发提醒 |
