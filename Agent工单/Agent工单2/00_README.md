# Agent工单2

这是根据《人工智能NLP-Agent数字人项目-02-日程提醒任务工单V1.1-20250206》完成的日程提醒智能体项目。

项目特性：
- 支持自然语言添加/查询/修改/删除日程
- 支持循环日程（每天/每周/每月）
- 到时自动提醒，多种温馨话术随机播报
- 使用 SQLite 持久化保存日程数据
- 提供 Web 界面，便于工单演示
- 后台调度器每分钟检查到期日程

目录结构：
- 设计：设计说明
- 研发：后端代码（数据库/解析/服务/调度/Web/日志）
- 测试：测试脚本与测试说明
- 优化：优化记录
- 部署：前端页面与配置

运行方式：
1. 进入项目目录
2. 安装依赖：
   pip install -r requirements.txt
3. 启动项目：
   python run.py
4. 浏览器打开：
   http://127.0.0.1:5051

推荐测试语句：
- 添加日程：下午5点开会
- 添加日程：每天早上8点提醒我起床
- 我今天的日程有哪些？
- 修改日程1 时间改为下午3点
- 确认修改
- 把日程2改成每天上午8点买咖啡
- 删除日程1
- 确认删除
- 取消日程2
- 明天上午9点提醒我交报告

数据库文件：
- schedule_notes.db

日志文件：
