# 设计说明

## 1. 项目目标
- 实现一个日程提醒智能体 Agent。
- 支持自然语言添加、查询、删除日程。
- 支持循环日程（每天/每周/每月）。
- 所有日程数据落到 SQLite 数据库 `schedule_notes.db`。
- 后台调度器每分钟检查到期日程，自动触发提醒。

## 2. 核心功能
- 添加日程：解析自然语言中的时间、事项、循环规则，写入数据库
- 查询日程：查看今日/明日/全部日程列表
- 删除/取消日程：按编号删除，需二次确认
- 修改日程：按编号修改时间/日期/内容/重复规则，需二次确认
- 循环日程：支持"每天X点"、"每周X"、"每月X号"等规则
- 到时提醒：后台调度器轮询，多种温馨话术随机播报
- 缺失信息补充引导

## 3. 数据表设计
表名：`schedules`
字段：
- `id`：主键，用于删除时的编号
- `schedule_time`：日程时间 (HH:MM 格式)
- `schedule_date`：日程日期 (YYYY-MM-DD，可为空表示每天)
- `content`：事项内容
- `repeat_rule`：循环规则 (none/daily/weekly/monthly)
- `repeat_detail`：循环详情（如每周的星期几）
- `enabled`：是否启用 (1=启用, 0=已取消)
- `last_reminded`：上次提醒时间
- `created_at`：创建时间

## 4. 流程说明
- 用户输入自然语言
- 规则解析输入意图（添加/查询/修改/删除）
- 提取时间、事项、循环规则
- 调用数据库完成增删查
- 后台调度器每分钟检查到期的启用日程
- 生成中文回复 / 提醒消息

## 5. 验收覆盖
- 开场白
- 测试语句可执行
- 数据 100% 落库
- 删除前二次确认
- 不完整输入做引导
- 循环日程正确解析
- 提醒话术随机播报
- 代码注释包含工单编号
