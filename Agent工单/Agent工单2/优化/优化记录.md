# 优化记录

## 工单编号：人工智能 NLP-Agent 数字人项目-日程提醒智能体任务

1. **SQLite 持久化落库**
   - 使用 SQLite 存储所有日程数据，确保数据不丢失。
   - 采用软删除（enabled=0）而非物理删除，保留数据可追溯。
   - row_factory = sqlite3.Row 提供字典式访问。

2. **规则解析优先策略**
   - 采用正则 + 关键词规则引擎进行自然语言解析。
   - 覆盖多种时间表达：数字时间（3点/15:00）、时段（下午/上午/晚上）、相对日期（今天/明天/后天）。
   - 支持循环规则解析：每天/每周X/每月X号。

3. **删除前二次确认**
   - 引入 pending_delete_id 状态机，删除前匹配并展示目标记录。
   - 用户需明确回复"确认删除"后才执行操作，降低误删风险。
   - 支持按编号删除和按关键词模糊匹配删除。

4. **后台定时提醒**
   - 独立调度线程每 10 秒轮询，整分钟触发检查。
   - 6 种不同话术模板随机选取，满足工单要求的多种提醒风格。
   - 提醒后记录 last_reminded 防止同一分钟重复提醒。

5. **项目结构规范化**
   - 根目录仅保留入口文件，功能代码按设计/研发/测试/优化/部署分类存放。
   - 所有代码注释包含工单编号，满足工单备注要求。
   - 目录结构与工单1保持一致，便于对比和维护。
6. **日程修改功能（增删改查完整性）**
   - 新增 update 意图解析：支持字段级修改（"时间改为X"）和整体替换（"改成每天X点Y"）
   - 新增 update_schedule 数据库方法：白名单过滤字段，动态构建 UPDATE SQL
   - 修改前展示前后对比，需回复"确认修改"后才执行，与删除流程保持一致的安全性
   - 支持修改时间、日期、内容、重复规则等全部字段
