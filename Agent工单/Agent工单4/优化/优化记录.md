# 优化记录 - 基金数据智能问答 NL2SQL

## V2.0 — 批量处理 + 日志系统 (2026-06-23)

### 新增功能
- 批量处理模式: python main.py --batch
- 断点续传: 中断后自动跳过已完成的题目
- 日志系统: 控制台+文件双通道，UTF-8中文支持
- 进度追踪: 每10题汇报进度、速率、预计剩余时间
- 异常容错: 单题失败不影响整体，自动写入空答案

### 改进
- main.py: argparse命令行参数支持
- 代码注释: 所有模块包含工单编号
- 文档完善: 设计说明、测试说明、部署说明、DB关系图

## V1.0 — 初始版本
- Flask Web服务 + NL2SQL引擎
- DeepSeek API集成
- SQLite 10张表查询
- 3个辅助视图预计算涨跌幅/涨停
- SQL自动错误修正（最多2次）
- PDF文本检索回退（RAG）
- 输入清洗（sanitize_question）
- 前端聊天UI（暗色主题）
