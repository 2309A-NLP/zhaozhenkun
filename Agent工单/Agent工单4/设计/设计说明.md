# 设计说明 - 基金数据智能问答 NL2SQL

## 架构

本项目是一个基于 NL2SQL (自然语言转SQL) 的基金/股票/债券数据智能问答系统。

### 系统架构层次

[浏览器前端] ←→ [Flask Web服务] ←→ [NL2SQL引擎] ←→ [SQLite数据库]

- 展示层: index.html 单页应用 (暗色主题·聊天UI)
- 接口层: Flask REST API (/api/chat, /api/health)
- 业务层: process_question() NL2SQL管线
- 解析层: prompt_builder.py 提示词工程 + deepseek_client.py API调用
- 数据层: db_explorer.py 数据库探索 + SQLite 10张表

### 数据流

用户自然语言问题 → sanitize_question() 清洗 → generate_sql() 生成SQL → DeepSeek API → extract_sql_from_response() 提取 → execute_sql() 执行 → format_sql_result() 格式化 → JSON响应

SQL执行失败时自动错误修正（最多2次），PDF类问题走RAG检索回退。

## 技术选型

| 组件 | 技术选型 | 理由 |
|------|---------|------|
| Web框架 | Flask | 轻量·Python生态·模板引擎 |
| LLM | DeepSeek v4-pro | 性价比·中文SQL能力强 |
| 数据库 | SQLite 1.46GB | 嵌入式·零运维 |
| 前端 | 原生HTML/CSS/JS | 无框架依赖·快速部署 |
| 批量处理 | batch_runner.py | 断点续传·进度保存 |
| 日志 | Python logging | 标准库·双通道输出 |

## 批量模式

python main.py --batch --questions question.jsonl --output-dir ./output
支持断点续传（--no-resume 从头开始）
输出: answer_result.jsonl
