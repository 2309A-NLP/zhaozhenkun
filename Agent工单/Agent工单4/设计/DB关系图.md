# 基金数据库表关系图

## 10张数据表

### 基金相关 (6张)
1. 基金基本信息 — 基金代码(PK), 基金简称, 管理人, 成立日期, 基金类型
2. 基金日行情表 — 基金代码(FK), 交易日, 单位净值, 累计净值
3. 基金规模变动表 — 基金代码(FK), 截止日期, 报告期总申购/赎回份额, 报告类型
4. 基金份额持有人结构 — 基金代码(FK), 截止日期, 机构/个人持有份额
5. 基金股票持仓明细 — 基金代码(FK), 股票代码, 持仓市值, 占净值比例
6. 基金债券持仓明细 — 基金代码(FK), 债券代码, 持仓市值
7. 基金可转债持仓明细 — 基金代码(FK), 对应股票代码, 持仓市值

### 股票相关 (3张)
8. A股票日行情表 — 股票代码, 交易日, 收盘价(元), 昨收盘(元), 成交量(股)
9. 港股票日行情表 — 股票代码, 交易日, 收盘价(元), 昨收盘(元), 成交量(股)
10. A股公司行业划分表 — 股票代码, 交易日期, 行业划分标准(中信/申万), 一级行业名称

## 核心JOIN关系

基金基本信息.基金代码 ←→ 基金日行情表.基金代码
基金基本信息.基金代码 ←→ 基金规模变动表.基金代码
基金基本信息.基金代码 ←→ 基金股票/债券/可转债持仓明细.基金代码
基金股票持仓明细.股票代码 ←→ A股票日行情表.股票代码
A股票日行情表.股票代码 + 交易日 ←→ A股公司行业划分表.股票代码 + 交易日期
基金可转债持仓明细.对应股票代码 ←→ A股票日行情表.股票代码

## 辅助视图（系统自动创建）

1. stock_daily_change — A股涨跌幅预计算: (收盘-昨收)/昨收*100
2. hk_stock_daily_change — 港股涨跌幅预计算
3. stock_limit_up — 涨停标记: (收盘/昨收-1)*100>=9.8
