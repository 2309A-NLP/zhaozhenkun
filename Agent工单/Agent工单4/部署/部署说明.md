# 部署说明 - 基金数据智能问答 NL2SQL

## 环境要求

- Python 3.10+
- 依赖: flask, requests, openai
- 数据集: bs_challenge_financial_14b_dataset (1.5GB+)
- 数据库: SQLite 1.46GB (博金杯比赛数据.db)

## 启动方式

### 1. 安装依赖
pip install flask requests openai

### 2. 下载数据集
# 从 ModelScope 下载
git clone https://www.modelscope.cn/datasets/BJQW14B/bs_challenge_financial_14b_dataset.git
# 或放到 ~/bs_challenge_financial_14b_dataset/

### 3. Web服务模式
cd 研发
python main.py
# 浏览器打开 http://127.0.0.1:5000

### 4. 批量处理模式
cd 研发
python main.py --batch
# 输出: answer_result.jsonl
# 支持断点续传，中断后重新运行自动跳过已完成

### 5. 指定题目文件
python main.py --batch --questions /path/to/question.json --output-dir ./output

### 6. 从头开始(不续传)
python main.py --batch --no-resume

## 输出文件
- answer_result.jsonl: 每行含 id, question, answer, elapsed
- batch_progress.txt: 已完成题目ID（断点续传）
- logs/fund_qa.log: 运行日志
