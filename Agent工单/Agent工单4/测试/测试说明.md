# 测试说明 - 基金数据智能问答 NL2SQL

## 测试用例

### 测试数据
- 题目文件: question.jsonl (1000题)
- 数据库: 博金杯比赛数据.db (1.46GB, 10张表)
- 数据类型: 基金/股票/债券/可转债/行业分类

### 测试方法

1. 单题测试 (Web模式):
   python main.py
   浏览器打开 http://127.0.0.1:5000
   输入测试问题

2. 批量测试:
   python main.py --batch
   输出: answer_result.jsonl

3. 快速验证:
   python -c "from 研发.config import *; print(DB_PATH, 'exists:', __import__('os').path.exists(DB_PATH))"

### 验收标准
- SQL生成正确率: 90%以上（通过3次自动修正）
- 单题平均耗时: <10秒
- PDF类问题: 正确回退到文本检索
- 输出格式: JSONL每行含id/question/answer/elapsed
