## 数据表设计

### department (科室)
| 字段 | 类型 | 说明 |
|------|------|------|
| dep_ID | INTEGER PK | 科室ID |
| dep_Name | VARCHAR(50) | 科室名称 |
| dep_Address | VARCHAR(200) | 科室位置 |

### doctor (医生)
| 字段 | 类型 | 说明 |
|------|------|------|
| d_ID | INTEGER PK | 医生ID |
| d_Name | VARCHAR(50) | 医生姓名 |
| d_Sex | CHAR(1) | 性别 |
| d_Profession | VARCHAR(50) | 职称(主任医师/副主任医师/主治医师) |
| dep_ID | INTEGER FK | 所属科室ID |

### patient (患者)
| 字段 | 类型 | 说明 |
|------|------|------|
| p_ID | INTEGER PK | 患者ID |
| p_Name | VARCHAR(50) | 姓名 |
| p_Sex | CHAR(1) | 性别 |
| p_Birth | DATETIME | 出生日期 |

### family_member (家庭成员)
| 字段 | 类型 | 说明 |
|------|------|------|
| fm_ID | INTEGER PK | 成员ID |
| p_ID | INTEGER FK | 所属患者ID |
| fm_Name | VARCHAR(50) | 成员名(大宝/二宝) |
| fm_Relation | VARCHAR(20) | 关系(儿子/女儿) |

### schedule (排班号源)
| 字段 | 类型 | 说明 |
|------|------|------|
| sch_ID | INTEGER PK | 号源ID |
| d_ID | INTEGER FK | 医生ID |
| sch_Date | DATE | 日期 |
| sch_Period | VARCHAR(10) | 时段(上午/下午) |
| sch_Total | INTEGER | 总号数 |
| sch_Remain | INTEGER | 剩余号数 |
| sch_Fee | INTEGER | 挂号费(元) |
| sch_Status | INTEGER | 状态(0=正常) |

### register (挂号记录)
| 字段 | 类型 | 说明 |
|------|------|------|
| reg_ID | INTEGER PK | 挂号ID |
| dep_ID | INTEGER FK | 科室ID |
| p_ID | INTEGER FK | 患者ID |
| d_ID | INTEGER FK | 医生ID |
| reg_Time | DATETIME | 挂号时间 |
| reg_Fee | INTEGER | 费用 |
| reg_Order | INTEGER | 序号 |
| reg_Status | INTEGER | 状态(0=已预约/1=已取消/2=已完成) |

## 状态流转

```
挂号 → reg_Status=0 (已预约)
     ├─ 就诊完成 → reg_Status=2 (已完成)
     └─ 取消 → reg_Status=1 (已取消) + schedule.sch_Remain+1
```
