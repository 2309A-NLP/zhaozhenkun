# 设计说明

## 1. 项目目标
- 实现一个家庭记账本 Agent（智能体）
- 支持自然语言记账、查询、删除
- 接入 LLM（DeepSeek）实现智能理解，支持口语化、模糊表达
- 所有账目落到 SQLite 数据库 `money_notes.db`

## 2. 核心功能
- 记一笔收入或支出（支持口语化表达，如"花了500块买了个包"）
- 智能分类：根据物品语义自动推断消费类别（如"三体"→"买书"）
- 查询单条记录（如"我哪天买的三体"）
- 查询月度汇总（如"这个月女儿花了多少钱"）
- 查询家庭本月明细（如"看下这个月家里花钱明细"）
- 删除指定记录（如"删除女儿报旅游团的费用"）
- 缺失信息补充引导（智能引导而非简单报错）
- 闲聊/打招呼友好回应

## 3. 数据表设计
表名：`money_notes`
字段：
- `id`：主键（自增）
- `record_date`：账目日期（YYYY-MM-DD）
- `member`：家庭成员（爸爸/妈妈/女儿/我）
- `action_type`：收入或支出
- `category`：类别（智能推断：买书、买鞋、餐饮、出行等）
- `item_name`：具体事项或物品
- `amount`：金额（元）
- `created_at`：创建时间戳

## 7. LLM 集成说明
- **模型**：DeepSeek Chat（deepseek-chat）
- **接口**：OpenAI 兼容 API（/v1/chat/completions）
- **降级策略**：LLM 不可用时自动切换为正则解析
- **温度参数**：0.1（低温度保证输出稳定性）
- **System Prompt**：内置家庭记账本角色设定、成员定义、输出格式规范
