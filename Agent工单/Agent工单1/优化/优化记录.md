# 优化记录

## V1.0（初始版本）
1. 使用 SQLite 落库，保证账目数据可持久化。
2. 采用规则解析，优先满足工单验收的固定问法。
3. 删除流程增加二次确认，降低误删风险。
4. Web 界面内置快捷测试按钮，便于验收。
5. 项目根目录保持干净，仅保留标准文件和分类目录。

## V2.0（LLM 智能化升级）

### 核心升级
6. **接入 LLM（DeepSeek）**：使用 DeepSeek Chat API 进行智能意图识别和信息提取，支持口语化、生活化的自然语言理解。
7. **智能分类**：不再依赖硬编码关键词映射，LLM 根据物品语义自动推断消费类别（如"三体"→"买书"、"肯德基"→"餐饮"）。
8. **智能引导**：当用户输入信息不完整时，LLM 生成友好的引导回复，而非生硬的错误提示。
9. **复杂理解能力**：支持模糊表达（如"花了500块"）、口语化称呼（如"老爸""闺女"）、省略句式等。

### 架构升级
10. **新增 llm_client.py 模块**：封装 OpenAI 兼容 API 调用，支持 DeepSeek / OpenAI / 其他兼容服务。
11. **LLM + 正则双模式**：LLM 优先解析，API 不可用时自动降级为正则规则解析，保证服务可用性。
12. **配置化**：LLM 相关参数（base_url、api_key、model、temperature）全部通过 config.json 配置。

### 质量改进
13. **工单编号修正**：所有源代码文件统一标注正确的工单编号。
14. **补充流程图**：设计说明中补充了完整的系统架构图和业务流程图。
15. **测试用例扩展**：新增口语化表达、智能分类、完整性引导等测试用例。
