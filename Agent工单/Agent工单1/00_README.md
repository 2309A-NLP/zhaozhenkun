# Agent工单1

这是根据《人工智能NLP-Agent数字人项目-01-记账本任务工单V1.1-20250206》完成的家庭记账本项目。

## 项目特性
- 支持自然语言记账（LLM 智能理解，支持口语化表达）
- 智能分类：根据物品语义自动推断消费类别
- 支持查询明细、月度汇总、购买日期
- 支持删除前确认
- 信息不完整时智能引导补充
- 使用 SQLite 持久化保存账目
- 提供 Web 界面，便于工单演示
- LLM 不可用时自动降级为正则解析

## 技术栈
- Python 3.10+
- Flask（Web 框架）
- SQLite（数据库）
- DeepSeek Chat（LLM，OpenAI 兼容 API）

## 目录结构
- 设计：设计说明（含流程图）
- 研发：后端代码（database / parser / service / llm_client / web_app / logger_config）
- 测试：测试脚本与测试说明
- 优化：优化记录
- 部署：前端页面与配置

## 运行方式
1. 进入项目目录
2. 安装依赖：
   ```
   pip install -r requirements.txt
   ```
3. 配置 LLM（可选，在 部署/config.json 中填写 llm_api_key）
4. 启动项目：
   ```
   python run.py
   ```
5. 浏览器打开：
   http://127.0.0.1:5050
