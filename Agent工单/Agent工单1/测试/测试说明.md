# 测试说明

## 工单标准测试语句

1. 今天女儿买了双登山鞋499元
2. 7月5日妈妈收到报销1000元
3. 看下这个月家里花钱明细
4. 这个月女儿花了多少钱
5. 删除女儿报旅游团的费用
6. 确认删除
7. 我哪天买的登山鞋

## 预期结果
- 第 1、2 条会写入 SQLite 数据库，且类别智能推断正确
- 第 3、4、7 条会正确查询
- 第 5 条先弹出确认
- 第 6 条完成删除
- 输入缺少金额、成员、日期时会友好引导补充

## LLM 智能理解测试（新增）

以下测试验证 LLM 的口语化理解和智能分类能力：

8. 昨天花了200块请朋友吃饭 → 应记录为：餐饮，支出200元
9. 上星期闺女买了个新书包花了180 → 应识别"闺女"为女儿，类别为服饰或日常记账
10. 老爸发工资8000 → 应识别"老爸"为爸爸，类别为工资，收入8000元
11. 花了500元 → 缺少成员，应引导补充"是哪位家庭成员？"
12. 买了一本书 → 缺少金额和成员，应引导补充

## 信息完整性引导测试

输入不完整信息时，系统应：
- 友好提示缺少哪个字段
- 给出正确的输入格式示例
- 不会直接记录残缺数据
