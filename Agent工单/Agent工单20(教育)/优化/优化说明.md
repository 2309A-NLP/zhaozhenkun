# 工单20 优化说明

## 已做优化
- 通过 `services` 拆分业务逻辑，保证每个 Python 文件控制在 300 行以内。
- 前端模型切换使用 `localStorage` 保留上次选择，减少重复切换操作。
- 复盘结果按“面试记录 + 模型提供方”双维度缓存，避免不同模型结果互相覆盖。
- 录音转写采用“供应商接口优先 + 降级文本兜底”模式，保证主流程稳定。
- 知识点匹配、本地评分、问题提取独立封装，便于后续替换为更强策略。

## 后续可优化方向
- 将批量导入模板从 JSON 扩展为 Excel。
- 将录音转写从降级提示升级为完整生产级 ASR。
- 引入更细粒度的岗位知识库和评分维度。
- 为复盘详情增加导出 PDF 能力。
- 将本地 JSON 存储升级为 SQLite/MySQL。
