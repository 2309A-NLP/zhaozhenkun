工单20 面试AI复盘 部署说明

1. 运行环境
- Python 3.10+
- Windows 11 / Linux / macOS
- 已安装 pip

2. 目录说明
- 部署：环境变量与依赖文件
- 研发：Flask 源码、模板、静态资源、JSON 数据
- 测试：测试用例与验证清单
- 设计：方案设计
- 优化：优化说明

3. 安装依赖
在项目根目录执行：
py -3 -m pip install -r 部署/requirements.txt

4. 配置模型
- 复制 `部署/.env.example` 内容到 `部署/.env.local`
- 已预留 DeepSeek 与千问的 base_url、API Key、模型名
- 默认模型开关通过 `DEFAULT_PROVIDER` 控制

5. 启动项目
在项目根目录执行：
py -3 研发/app.py

6. 访问地址
- 首页：`http://127.0.0.1:5020/`
- 健康检查：`http://127.0.0.1:5020/api/health`

7. 使用说明
- 首页默认展示“就业面试复盘工作台”，包含记录统计、关键词检索、来源筛选和批量导入入口。
- 建议演示路径：先查看首页统计，再点开李明或周倩的记录，最后进入“面试AI复盘”详情页。
- 点击“批量导入记录”可按 JSON 模板导入学生面试记录。
- 点击学生姓名可查看详情，并在规则允许时修改。
- 上传录音后会保存到 `研发/uploads/`。
- 复盘详情页支持切换模型、重新生成复盘，并查看总体评价、问题解析、AI优化版与原始记录对照。

8. 录音转写说明
- 当前版本优先尝试千问兼容 ASR 接口。
- 若供应商接口不通或音频能力不可用，系统自动降级为“已接入上传流程”的提示文本，不影响复盘页面演示。

9. 注意事项
- 由于 git 根目录不是本项目目录，提交代码前请先人工确认变更范围。
- `部署/.env.local` 已加入 `.gitignore`，避免模型密钥误提交。
