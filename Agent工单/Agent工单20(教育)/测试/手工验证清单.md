# 工单20 测试用例与手工验证清单

## 1. 首页列表
- 打开首页后能看到面试列表字段：学生、岗位名称、面试轮次/形式、面试城市/时间、上报人、上报时间、面试AI复盘。
- 有录音的记录展示“面试AI复盘”入口。
- 无录音的记录展示“无录音”。

## 2. 模型切换
- 首页可在 DeepSeek 与千问之间切换。
- 点击复盘入口后会带上当前选择的模型。
- 在复盘详情页切换模型后页面重新加载并更新模型标识。

## 3. 批量导入
- 点击“批量导入”后弹出导入对话框。
- 粘贴 JSON 数组后可成功导入。
- 重复 `id` 的记录不会重复写入。

## 4. 详情查看与编辑
- 点击学生姓名可进入详情页。
- 两天内或“待完善”状态记录支持编辑。
- 超出规则的记录只读。
- 保存后上报人会更新为学生姓名。

## 5. 录音上传
- 支持 mp3、wav、m4a、aac、ogg。
- 非支持格式会返回错误提示。
- 上传成功后记录内保存文件名与转写文本。
- 不在“两天内”且不为“待完善”的记录，不能补传录音。

## 6. AI复盘详情
- 仅存在录音文件的记录展示并允许进入“面试AI复盘”。
- 页面展示综合得分、总体评价、自我介绍点评、修改建议。
- 页面展示问题解析表格。
- 页面左右展示 AI优化版 与 完整原记录。

## 7. 接口验证
- `GET /api/health` 返回 `ok=true`。
- `GET /api/models` 返回模型状态。
- `POST /api/interviews/import` 返回导入数量。
- `POST /api/reviews/<id>` 返回复盘结构。
