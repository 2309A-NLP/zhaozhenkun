# 数字人与智能体集成 — 实现步骤记录

工单编号: 人工智能NLP-Agent数字人项目-数字人与智能体的集成任务
创建日期: 2025-01-14
实现日期: 2026-06-24

## 一、需求分析

将《08-实时数字人交互任务工单》的"对接大模型实现对话功能"升级为"对接智能体实现各种任务的交互"。

核心变化:
- 语音识别: Whisper → FunASR (SenseVoiceSmall)
- 语音合成: EdgeTTS → GPT-SoVITS (支持声音克隆)
- 数字人: Wav2Lip → liveTalking
- 对话: LLM直接对话 → Agent工具路由(记账/日程/文生图/基金/招股书)

## 二、实现步骤

### 步骤1: FunASR语音识别引擎 (研发/asr_engine.py)
- 使用modelscope加载SenseVoiceSmall模型
- 支持VAD语音活动检测（自动分割说话段）
- CPU推理优化，不占用GPU显存
- Whisper自动回退机制（FunASR不可用时）
- 异步转录接口 + 同步文件转录

### 步骤2: GPT-SoVITS语音合成引擎 (研发/tts_engine.py)
- HTTP API调用独立部署的GPT-SoVITS服务
- 支持零样本声音克隆（上传参考音频）
- 声音克隆样本管理（voice_samples/目录）
- EdgeTTS自动回退（GPT-SoVITS不可用时）
- WAV/MP3多格式解码 + FFmpeg兜底

### 步骤3: liveTalking数字人引擎 (研发/digital_human.py)
- 加载数字人形象（PNG/MP4）
- 占位模式：基于音频时长生成静态帧序列
- 真实推理模式：模型就绪后无缝切换
- 音视频FFmpeg合成（MP4输出）
- 异步GPU推理（独立线程池）

### 步骤4: Agent集成服务 (保留原有)
- DeepSeek v4-pro 意图识别
- 5工具路由：记账/日程/文生图/基金/招股书
- 多轮对话 + session管理
- demo_qa.db预匹配加速

### 步骤5: 语音管线集成 (研发/main.py)
- POST /api/voice/chat：音频→ASR→Agent→TTS→视频
- SLA性能监控：各阶段延迟追踪
- MJPEG视频流：/api/video/stream
- 声音克隆：POST /api/voice/clone
- TTS独立端点：POST /api/tts

### 步骤6: 前端语音UI (部署/templates/index.html)
- 🎤麦克风录音（WebM/Opus编码）
- TTS音频自动播放
- 数字人MJPEG视频展示
- 多语言切换（中文/English）
- 保留全部原有文本对话功能

## 三、遇到的问题与解决

### 问题1: FunASR模型加载慢
- 现象: SenseVoiceSmall首次加载需10-20秒
- 解决: 延迟加载（首次使用时加载）+ 全局单例复用

### 问题2: GPT-SoVITS服务可能不可用
- 现象: 独立部署的服务未启动时TTS失败
- 解决: EdgeTTS自动回退机制，确保TTS始终可用

### 问题3: liveTalking模型需要特定训练
- 现象: liveTalking需要针对具体数字人形象训练
- 解决: 占位模式生成静态帧+音频正常输出，模型就绪后可切换

### 问题4: 响应时间SLA保障
- 要求: 数字人响应时间≤3秒
- 措施: 
  - FunASR CPU推理 < 500ms
  - Agent意图识别 < 500ms  
  - Agent工具调用 < 1000ms
  - GPT-SoVITS TTS < 1700ms
  - 各阶段SLA监控 + metrics实时追踪
